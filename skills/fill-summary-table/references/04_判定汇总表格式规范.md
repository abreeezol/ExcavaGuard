# 判定汇总表（10 列版式）格式规范

> 本文件描述 `--layout verdict` 输出的「判定汇总表」的**精确版式**与 **I / J 两列的口径**，
> 供填表脚本严格复刻、供复核人逐列核对。
> 样例来源：用户提供的样例图片（`baf718938ed5f5effac0e61cba10a21a.png`）。

---

## 1. 版式总览

一行 = 一个测点，10 列，**第 1 行即表头**（无标题行、无抬头行）：

| 列 | 列名（表 C 示例） | 含义 | 数据类型 |
|:--:|---|---|---|
| A | 监测项目 | 土压力 / 孔隙水压力 / 围护墙内力 / 立柱内力 / 支撑轴力 / 锚杆轴力 | 文本 |
| B | 点号 | 测点编号，如 `TY-01`、`ZL-01` | 文本 |
| C | 本次变化量(kPa) | 末期测值 − 相邻上一期测值 | 数值 |
| D | 变化速率(kPa/d) | 本次变化量 ÷ 实际采样间隔（天） | 数值 |
| E | 累计变化量(kPa) | 末期测值 − 该测点首期测值 | 数值 |
| F | 报警值(kPa) | 规范区间**下限**（或设计值占比下限） | 数值 / 文本 |
| G | 控制值(kPa) | 规范区间**上限**（或设计值占比上限） | 数值 / 文本 |
| H | 等级 | `正常` / `黄色` / `橙色` / `红色` / `未知` | 文本 |
| **I** | **规范条文** | **判据所在的规范表号 / 条文号；判据库无该项时填 RAG 命中标识** | 文本 |
| **J** | **规范依据摘要** | **判据来源 + 限值 + 知识库命中的合成摘要** | 文本 |

- 单位随监测项目自适应：表 C 类为 `kPa`，表 D 类为 `kN`（写入列名）。
- 一张 sheet 只放同一张表（表 C 或表 D）的测点，避免同列混单位。
- 版式设置：冻结首行（`A2`）、首行自动筛选。

### 1.1 样例图片逐列核对（反向验证）

样例图片的数值可以完全反推出口径，这是本规范的事实依据：

| 监测项目 | 点号 | 本次变化量 | 变化速率 | 累计变化量 | 报警值 | 控制值 | 等级 | 规范条文 |
|---|---|--:|--:|--:|--:|--:|:--:|---|
| 地下水水位 | SW-01 | 0.23 | 66.24 | 192.746 | 1000 | 2000 | 正常 | 表8.0.5 |
| 地下水水位 | SW-07 | 1.199 | 345.312 | 2089.534 | 1000 | 2000 | 红色 | 表8.0.5 |
| 周边地表竖向位移 | DBC-01 | −0.002 | 0.576 | −5.065 | 25 | 35 | 正常 | 表8.0.4 |
| 周边地表竖向位移 | DBC-07 | −0.019 | 5.472 | −37.629 | 25 | 35 | 红色 | 表8.0.4 |
| 土体分层竖向位移 | FC-01 | 0.001 | 0.288 | 2.422 | 未知 | 未知 | 未知 | RAG命中 GB50497-2019 |
| 坑底隆起(回弹) | KB-01 | 0.031 | 8.928 | 61.163 | 30 | 60 | 红色 | 表8.0.4 |
| 坑底隆起(回弹) | KB-03 | 0.005 | 1.44 | 7.06 | 30 | 60 | 正常 | 表8.0.4 |

**反推出的三条口径**：

1. `变化速率 ÷ 本次变化量 = 288`（每一行都成立）→ 采样间隔 **5 分钟**，
   `变化速率 = 本次变化量 ÷ (5/1440) d`。
2. **红色 ⟺ `|累计变化量| ≥ 控制值`**：
   `2089.534 ≥ 2000` ✓、`|−37.629| ≥ 35` ✓、`61.163 ≥ 60` ✓；
   其余各行 `|累计变化量| < 报警值` → `正常` ✓。
3. **`未知` ⟺ 判据库无该项**：「土体分层竖向位移」在 GB 50497-2019 表 8.0.4 / 8.0.5
   中**未给出预警值**，故报警值 / 控制值 / 等级均为 `未知`，规范条文退化为
   `RAG命中 GB50497-2019` ✓。

同时验证了报警值 / 控制值的取法 —— 与内置判据库**逐项吻合**：

| 监测项目 | 判据库 | 报警值（区间下限） | 控制值（区间上限） |
|---|---|--:|--:|
| 地下水位 | 表 8.0.5 累计值 1000~2000 mm | 1000 | 2000 |
| 周边地表竖向位移（一级） | 表 8.0.4 累计值 25~35 mm | 25 | 35 |
| 坑底隆起（回弹） | 表 8.0.4 累计值 30~60 mm | 30 | 60 |

## 2. I 列 · 规范条文

判定顺序（**先查判据库，再退知识库**）：

| 情形 | I 列取值 | 说明 |
|---|---|---|
| 内置判据库中该监测项**有适用判据** | `表8.0.4` 或 `表8.0.5`（取自 `rules[].evidence.clause`） | 与样例图片一致 |
| 判据库中该监测项**无判据**（如「立柱内力」），但知识库有命中 | `RAG命中 GB50497-2019` | 与样例图片中「土体分层竖向位移」一致 |
| 两者皆无 | `无适用条文` | **不得臆造表号或条文号** |

> 「立柱内力」在 GB 50497-2019 表 8.0.4 中**未给出预警值**（判据库 `limit_mode = none`），
> 因此与样例中「土体分层竖向位移」走同一条退化路径。

## 3. J 列 · 规范依据摘要

按下列片段用 `；` 拼接：

```
[判据库片段]  依据{表号}（GB 50497-2019[，{规范原注}]）
              ├─ 位移/水位类：{表号}：累计值 {下限}~{上限} {单位}，变化速率 {限值} {单位}/d
              └─ 内力/轴力类：判定对象为本次测值，限值 {60%~80%f2}
                              （已提供设计值时：{表号}：最大值 60%~80%f2，f2=800 kN
                               → 报警值 480 kN、控制值 640 kN）
[RAG 片段]    RAG命中《{规范名}》{条文号}（相关度 {score}）
              └─ 判据库无该项时追加命中摘要：：{摘要前 60 字}…
[降级片段]    未接入知识库，未做 RAG 命中
```

实际示例（表 D · 支撑轴力）：

```
依据表8.0.4（GB 50497-2019，最大值 (60%~80%) f2，f2 为构件承载能力设计值）；
判定对象为本次测值，限值 60%~80%f2；
RAG命中《GB50497-2019 建筑基坑工程监测技术标准》（相关度 0.7977）
```

与样例图片的 `依据表8.0.5; RAG命中 …` 同构，只是把限值推导过程一并写出，便于复核。

## 4. 报警值 / 控制值 取法

| 判据类型 | 判据库字段 | 报警值 | 控制值 | 判定对象 |
|---|---|---|---|---|
| 位移 / 水位类 | `cumulative_mm{min,max}` | `min` | `max` | **累计变化量** |
| 内力 / 轴力类（上限） | `max_ratio_of_design{min,max}` | `min×设计值` | `max×设计值` | **本次测值** |
| 内力 / 轴力类（下限，锚杆） | `min_ratio_of_design{min,max}` | `min×设计值` | `max×设计值` | **本次测值** |
| 无判据 | — | `未知` | `未知` | — |

- **未提供设计值**时，报警值 / 控制值以占比文本展示（如 `60%f2`、`80%fy`），
  等级为 `未知`（无法换算绝对量限值 → 弃权）。
- 设计值通过 `--design design.json` 传入，如 `{"支撑轴力": 800, "锚杆轴力": 300}`。
- 显式 `--limits limits.json`（绝对量 `warn` / `control` / `rate`）优先级最高。

## 5. 等级判定

| 判据类型 | 规则 |
|---|---|
| 位移 / 水位类（累计量） | `\|累计\| ≥ 控制值` → 红色；`≥ 报警值` → 橙色；`≥ 报警值×70%` → 黄色；否则 正常 |
| 位移 / 水位类（速率） | `\|变化速率\| ≥ 速率限值` → 至少 橙色 |
| 内力 / 轴力类（上限） | `测值 ≥ 控制值` → 红色；`≥ 报警值` → 橙色；否则 正常 |
| 内力 / 轴力类（下限，锚杆） | `测值 < 报警值` → 红色（预应力松弛）；`> 控制值` → 橙色；否则 正常 |
| 判据缺失 / 设计值缺失 / 数据缺失 | `未知` |

> 样例图片只出现 `正常` / `红色` / `未知` 三种取值，是数据分布使然；
> 本表在其之上补齐 `黄色` / `橙色` 两档（与「示例汇总表」的五级口径一致）。

> ⚠️ **`未知` 表示弃权，不是「安全」**，必须转人工复核，禁止渲染为正常项。

## 6. 期次口径与变化速率

`--period` 控制「本次」的取法：

| 取值 | 本次变化量 | 变化速率 | 适用 |
|---|---|---|---|
| `interval`（**默认**） | 末期测值 − **相邻上一期**测值 | 本次变化量 ÷ 实际采样间隔（天） | 与样例图片一致；自动化高频监测 |
| `daily` | 当日末次 − 前日末次 | 本次变化量 ÷ 间隔天数 | 传统日报口径（间隔 1 天时速率 = 变化量） |

`--period interval` 下，若采样间隔为 5 分钟，则速率为变化量的 **288 倍**
（外推值，仅供趋势参考）；实际间隔会写入「说明」页，避免误读。

## 7. 输出工作簿结构

| sheet | 内容 |
|---|---|
| `表C判定汇总` | 表 C 类测点（土压力、孔隙水压力、围护墙内力、立柱内力），单位 kPa |
| `表D判定汇总` | 表 D 类测点（支撑轴力、锚杆轴力），单位 kN |
| `说明` | 抬头 / 判据来源 / 判定口径 / 边界声明 / 限值推导过程 / RAG 命中明细 / 签署栏 |

> 两张判定汇总 sheet 与样例图片**逐列同构**；因表 C（kPa）与表 D（kN）单位不同，
> 拆为两张 sheet 以保持「一列一单位」。

## 8. 边界声明（必须写入「说明」页）

1. 本表为监测数据整理与判定的**辅助材料**，不替代责任单位出具的正式监测报告。
2. 本表为**判定汇总视图**，不替代 GB 50497-2019 附录 C / D 的原始记录表式。
3. 判定阈值以**项目专项监测方案**为准（GB 50497-2019 第 8.0.1 条：
   监测预警值应由基坑工程设计方确定）。
4. 红色等级须经人工确认，正式预警发布与工程处置沿用既有责任流程。
5. 表中「—」表示数据源未提供或该期数据缺失，**未作插值填补**。
