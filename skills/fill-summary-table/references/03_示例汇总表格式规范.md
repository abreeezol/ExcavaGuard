> 行号均为 **0-based**（与 `openpyxl` 的 `min_row` 差 1），Excel 行号 = 索引 + 1。

## 4. 清洗与填充规则

### 4.1 列名映射（输入 → 规范字段）

| 规范字段 | 接受的输入列名 |
|---|---|
| 时间 | `时间`、`日期`、`观测日期`、`监测时间`、`timestamp`、`date`、`time` |
| 点号 | `点号`、`测点`、`测点号`、`测点编号`、`point_id`、`point` |
| 监测项目 | `监测项目`、`项目`、`监测项`、`metric`、`item` |
| 测值 | `测值`、`本次测值`、`观测值`、`value`、`reading` |
| 单位 | `单位`、`unit` |
| 深度 | `深度`、`深度(m)`、`埋深`、`depth`、`depth_m` |
| 组号 | `组号`、`group` |
| 备注 | `备注`、`remark`、`note` |

### 4.2 时间解析

依次尝试：`%Y-%m-%d %H:%M:%S`、`%Y-%m-%d %H:%M`、`%Y-%m-%d`、`%Y/%m/%d %H:%M`、`%Y/%m/%d`、
`%Y.%m.%d`、`%Y年%m月%d日`、ISO 8601。**解析失败的行不丢弃**，记入待复核并置预警等级为 `未判定(待复核)`。

### 4.3 单位归一化

| 输入 | 归一为 | 换算 |
|---|---|---|
| `kpa`、`KPa`、`kPa`、`千帕` | kPa | ×1 |
| `mpa`、`MPa`、`兆帕` | kPa | ×1000 |
| `pa` | kPa | ÷1000 |
| `kn`、`KN`、`kN`、`千牛` | kN | ×1 |
| `n` | kN | ÷1000 |

> **表 C 只接受压力类单位（→kPa），表 D 只接受力类单位（→kN）**；类型不匹配的行记入待复核。

### 4.4 派生量计算

| 派生字段 | 规则 |
|---|---|
| 上次测值 | 同测点按时间排序后的**前一期**测值；首期等于本期 |
| 本次变化 | `本次测值 − 上次测值` |
| 累计变化 | `本次测值 − 该测点首期测值`（基准值） |

> 若输入已自带 `上次测值` / `累计变化`，**以输入为准**，但须校验
> `本次变化 = 本次测值 − 上次测值`；超差（>0.5）时写入备注并置 `未判定(待复核)`。

### 4.5 预警等级判定

| 条件 | 等级 |
|---|---|
| 无阈值配置 | `未判定(待复核)` |
| 数值缺失 / 单位异常 / 时间不可解析 / 变化量不自洽 | `未判定(待复核)` |
| `\|累计变化\| ≥ 控制值` 或 `\|变化速率\| ≥ 速率限值` | `红色预警` |
| `\|累计变化\| ≥ 报警值` 或 速率达标 | `橙色预警` |
| `\|累计变化\| ≥ 报警值 × 70%` 或 速率 ≥ 70% 限值 | `黄色预警` |
| 以上均不满足 | `正常` |

> **阈值来源**：项目专项监测方案（GB 50497-2019 第 8.0.1 条规定预警值由设计方确定）。
> 未提供阈值时**一律不作判定**，不得默认为「正常」。

### 4.6 分组（组号）

| 组号 | 监测项目 | 目标表 |
|:--:|---|---|
| 1 | 围护墙内力、立柱内力、土压力、孔隙水压力 | 表 C（kPa） |
| 2 | 支撑轴力 | 表 D（kN） |
| 3 | 锚杆轴力 | 表 D（kN） |

> 若输入自带组号则以输入为准；否则按监测项目名自动归类。

## 5. 必须写入的边界声明

填充后的文件必须体现以下三条（写入汇总页「七、说明」）：

1. 本表为监测数据分析与日报编制的**辅助材料**，由责任人员复核后进入签发、归档流程，
   **不替代**责任单位出具的正式监测报告。
2. 表式以 GB 50497-2019 附录 A~G 为基准；**格式修改**：①各表增加「预警等级」列；
   ②表 B 增加「点号」列；③超限与待复核信息写入「备注」列并在汇总页集中列示。
3. 判定阈值以**项目专项监测方案**为准；**未配置阈值的一律不作判定**。
   红色预警须经人工确认，正式预警发布与工程处置沿用既有责任流程。

> `未判定(待复核)` 表示**弃权，不是「安全」**，必须转人工复核，禁止渲染为正常项。
