## 3. 可复用的字段特征（来自隧道数据集）

### 3.1 时序数据字段结构（`observations.csv`）

| 字段 | 类型 | 示例 | 复用建议 |
|---|---|---|---|
| `timestamp` | 日期时间 | `2020-10-15 00:00:00` | ✅ 采用同格式 `YYYY-MM-DD HH:MM:SS` |
| `sensor_id` | 文本 | `MG-001` | ✅ 采用同命名：`类型前缀-序号` |
| `sensor_type` | 枚举 | `DW` / `MG` / `SY` | ✅ 扩展：`TY`(土压力) `KL`(孔压) `ZL`(支撑轴力) `MG`(锚杆轴力) `LZ`(立柱内力) `QN`(墙内力) |
| `channel_id` | 文本 | `orifice` / `5m` / `2m` / `stress` / `pressure` | ✅ 采用 `stress` / `pressure` / 深度标记 |
| `depth_m` | 数值 | `0` / `3` / `6` | ✅ 采用（表 C/D 的「深度(m)」列） |
| `engineering_value` | 数值 | `2.7426` | ✅ 采用（表 C/D 的「本次测值」列） |
| `unit` | 文本 | `MPa` / `kPa` | ✅ 采用（表 C 用 kPa，表 D 用 kN） |
| `quality_flag` | 枚举 | `baseline` / `valid` | ✅ 采用并扩展（见 3.2） |

### 3.2 质量标记约定（`quality_flag`）

现有取值：`baseline`（基准期）、`valid`（有效）。

模拟数据建议扩展为：

| 取值 | 含义 |
|---|---|
| `baseline` | 基准期（首期，用于计算累计变化） |
| `valid` | 有效观测 |
| `suspect` | 可疑（数值偏离历史波动） |
| `missing` | 缺测 |
| `outlier` | 粗差 |

### 3.3 传感器元数据字段（`sensor_metadata.csv`）

| 字段 | 示例 | 复用建议 |
|---|---|---|
| `sensor_id` | `MG-001` | ✅ |
| `sensor_type` | `MG` | ✅ |
| `depth_m` | `3` | ✅ |
| `range_info` | `0~100mm` / `0~0.35Mpa` | ✅ 采用同格式描述量程 |
| `k_coeff` | `0.122` | ✅ 保留（传感器标定系数） |

### 3.4 阈值配置字段（`label_thresholds.csv`）

现有 44 通道 × 4 指标：`delta_abs_q95`（相邻变化）、`step_abs_q95`（阶跃）、`slope_abs_q95`（斜率）、`flatline_ratio_threshold`（漂移比）。

**注意**：这是**统计分位数**（数据驱动阈值），**不是**规范判据。表 C/D 的「预警等级」应按**项目专项监测方案**的累计值/速率双控限值判定，二者不可混用。

## 6. 结论汇总

| 问题 | 结论 |
|---|---|
| 现有数据是否已包含表 C/D 所需内容？ | **否**。无围护墙内力、立柱内力、土压力、支撑轴力；孔隙水压力与锚杆应力仅有**同类但不同量级/单位**的隧道数据 |
| 是否可直接转换？ | **不可**。MG 为 MPa（应力），表 D 需 kN（轴力），单位维度不同；SY 量级远小于基坑工况 |
| 可复用什么？ | ✅ 字段命名（`sensor_id`/`depth_m`/`engineering_value`/`unit`/`quality_flag`）、时间戳格式、传感器元数据与阈值配置的组织方式 |
| 工况如何标定？ | ✅ 浅基坑按案例库实测分布（12~18 m）；深基坑按案例库上界与工程常识（25~38 m）；超深基坑（50~100 m）**案例库无参考，须显式声明** |
| 因此模拟数据 | **必须新生成**，并明确标注为模拟数据（不得与真实数据混同统计） |
