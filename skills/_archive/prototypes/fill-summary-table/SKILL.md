# 基坑监测数据规范化填表（三种表式）

把**杂乱的**监测数据，按 GB 50497-2019 的表式规范整理。三种输出形态**互不影响，可任选或同时产出**：

| 输出形态 | `--layout` | 表式 | 覆盖监测项 |
|---|---|---|---|
| 规范表式（默认） | `cd` | 「示例汇总表」式：`表C` / `表D` / `汇总` | 表 C / 表 D |
| **判定汇总表** | `verdict` | 10 列（含 `规范条文`、`规范依据摘要`） | 表 C / 表 D |
| **附录原表式** | `af` | 抬头 5 行 + **表头第 6 行** + 备注内嵌判定 | 默认 **表 C / 表 D**；`--tables cdef` 加 表 E / 表 F |
| 两者同时 | `both` | `cd` + `verdict` | — |
| 三者同时 | `all` | `cd` + `verdict` + `af` | — |

## 触发条件

- 用户提供监测原始数据（CSV / TSV / XLSX），来源格式不一：列名不统一、单位大小写混乱、
  时间格式混杂、含标题行与空行、含非目标表的监测项目。
- 用户提供 **GB 50497 附录原表式**工作簿（抬头 5 行、表头第 6 行、组号点号在末尾、
  **无「监测项目」列**、预警等级内嵌在「备注」里）—— 脚本可直接读取。
- 用户要求「按规范格式整理」「填进汇总表」「做成表 C / 表 D / 表 E / 表 F」「按 GB 50497 附录表式输出」。
- 用户要求「判定汇总表」「带规范条文 / 规范依据摘要的汇总表」「按样例图片的排版输出」。
- 用户要求「把附表 E / 附表 F 单独提取出来」「按某个工作簿的附表版式输出」。

覆盖的监测项目：

| 表 | 监测项目 | 单位 |
|:--:|---|:--:|
| C | 围护墙内力、立柱内力、土压力、孔隙水压力 | kPa |
| D | 支撑轴力、锚杆轴力 | kN |
| E | 地下水位、周边地表竖向位移、土体分层竖向位移、坑底隆起 | mm |
| F | 裂缝 | mm |

**不适用于**：表 A（水平位移、竖向位移）、表 B（深层水平位移）、表 G（巡视检查）。
这两类数据会被**明确识别并记入待复核**，注明「不在本 Skill 处理范围」，**不静默丢弃**。

| `--design` | | **可选增强**：设计值 JSON，如 `{"支撑轴力": 800, "锚杆轴力": 300}`；用于把规范的设计值占比换算为绝对量限值 |

| `--report` | | 可选：把清洗与判定报告写入 JSON |

### 输入表格形态（三种都支持，自动识别）

**① 长表**（每行一条记录）

| 时间 | 点号 | 监测项目 | 测值 | 单位 |
|---|---|---|---|---|
| 2026-10-01 00:00 | TY-01 | 土压力 | 27.5 | kPa |

**② 宽表**（一行 = 一个时刻，一列 = 一个测点）

| 时间 | 土压力 TY-01 (kPa) | 土压力 TY-02 (kPa) | 支撑轴力 ZL-01 (kN) | … |
|---|---|---|---|---|
| 2026-10-01 00:00 | 27.5 | 55.9 | 493.3 | … |

**③ GB 50497 附录原表式**（抬头 5 行 → **表头第 6 行** → 数据 → 页脚）

| 深度(m) | 本次测值 | 上次测值 | 本次变化 | 累计变化 | 组号 | 点号 | 备注 |
|---|---|---|---|---|---|---|---|
| — | 130 | 110 | 20 | 130 | — | CK-01 | 预警等级：红色(报警)；报警值：112 kN·m / kPa；占报警值：116.1%；超报警值：是 |

脚本**自动识别**：

- 表头中 ≥2 列匹配 `{监测项目} {测点号} ({单位})` 模式 → 按**宽表**处理并自动融化为长表；
- 表头在第 6 行、**无「监测项目」列** → 按**附录表式**处理，用**点号前缀**反推监测项目
  （`CK`→孔隙水压力、`CN`→围护墙内力、`EB`→坑底隆起、`F`→裂缝…），
  并从「备注」中解析 `预警等级` / `报警值` / `占报警值`；页脚行与非记录表 sheet 自动跳过。

> 宽表可识别的监测项目名：土压力、孔隙水压力、围护墙内力、立柱内力、支撑轴力、锚杆轴力、
> 地下水位、周边地表竖向位移、土体分层竖向位移、坑底隆起、裂缝。

| 规范字段 | 接受的列名 |

| 点号 | 点号、测点、测点号、测点编号、point_id、point、sensor_id |
| 监测项目 | 监测项目、项目、监测项、metric、item、sensor_type |
| 测值 | 测值、本次测值、观测值、实测值、数值、value、reading |
| 单位 | 单位、计量单位、unit |
| 深度 | 深度、深度(m)、埋深、depth、depth_m |
| 预警等级 | 预警等级、预警、等级、level |
| 上次测值 | 上次测值、上期测值、previous_value |
| 累计变化 | 累计变化、累计值、cumulative |
| 备注 | 备注、说明、remark、note |

### 单位归一

- 压力类（表 C → kPa）：`kPa` / `kpa` / `千帕` = ×1；`MPa` = ×1000；`Pa` = ÷1000
- 力类（表 D → kN）：`kN` / `kn` / `千牛` = ×1；`N` = ÷1000；`MN` = ×1000

量纲不符（如表 C 项目填了 `mm`）的行**不丢弃**，记入待复核。

### 时间格式容错

依次尝试 `%Y-%m-%d %H:%M:%S`、`%Y-%m-%d %H:%M`、`%Y-%m-%d`、`%Y/%m/%d %H:%M`、
`%Y/%m/%d`、`%Y.%m.%d`、`%Y年%m月%d日`、ISO 8601、`%Y%m%d`。
解析失败的行**不丢弃**，记入待复核并置 `未判定(待复核)`。

## 输出

### 形态一：`--layout cd`（默认）—— 规范表式工作簿

一个 xlsx，含 3 个 sheet：

| sheet | 内容 |
|---|---|
| `表C` | 围护墙内力、立柱内力及土压力、孔隙水压力监测日报表（kPa） |
| `表D` | 支撑轴力、锚杆轴力监测日报表（kN） |
| `汇总` | 七段式：结果汇总 / 超限清单 / 待复核 / 工况描述 / 分析结论 / 签署 / 说明 |

### 形态二：`--layout verdict` —— 判定汇总表（独立文件）

一个 xlsx，含 3 个 sheet：

| sheet | 内容 |
|---|---|
| `表C判定汇总` | 表 C 类测点，单位 kPa |
| `表D判定汇总` | 表 D 类测点，单位 kN |
| `说明` | 抬头 / 判据来源 / 判定口径 / 边界声明 / 限值推导过程 / RAG 命中明细 / 签署栏 |

两张判定汇总 sheet 的版式（**第 1 行即表头，第 2 行起为数据**）：

| A | B | C | D | E | F | G | H | I | J |
|---|---|---|---|---|---|---|---|---|---|
| 监测项目 | 点号 | 本次变化量(单位) | 变化速率(单位/d) | 累计变化量(单位) | 报警值(单位) | 控制值(单位) | 等级 | **规范条文** | **规范依据摘要** |

**I 规范条文**（先查判据库，再退知识库）：

| 情形 | 取值 |
|---|---|
| 内置判据库（GB 50497-2019 表 8.0.4 / 表 8.0.5）中该项**有适用判据** | `表8.0.4` / `表8.0.5` |
| 判据库中该项**无判据**（如「立柱内力」），知识库有命中 | `RAG命中 GB50497-2019` |
| 两者皆无 | `无适用条文`（**不得臆造表号或条文号**） |

**J 规范依据摘要**：`依据{表号}（GB 50497-2019[，规范原注]）；{限值推导}；RAG命中《{规范名}》{条文号}（相关度）`；
判据库无该项时以 `RAG命中《…》…：{摘要}` 为主；知识库未接入时注明「未接入知识库，未做 RAG 命中」。

**报警值 / 控制值**：判据库区间**下限 = 报警值、上限 = 控制值**；
内力/轴力类为设计值占比，未提供 `--design` 时以占比文本（如 `60%f2`）展示且等级为 `未知`。

**等级**：位移/水位类按 `|累计变化量|` 比对（≥控制值→红色、≥报警值→橙色、≥报警值×70%→黄色）；
内力/轴力类按**本次测值**比对；判据或设计值缺失 → `未知`（**弃权，不是「安全」**）。

> 完整口径（含样例图片的逐列反向验证）见 `references/04_判定汇总表格式规范.md`。

### 形态三：`--layout af` —— 附录 C / D / E / F 原表式

一个 xlsx，含 4 张 sheet（**按参考工作簿 `监测日报_附表AF_RAG.xlsx` 逐行复刻**）：

| sheet | 表头（第 6 行） |
|---|---|
| `附表C_围护墙内力等监测日报表` | `深度(m)｜本次测值｜上次测值｜本次变化｜累计变化｜组号｜点号｜备注` |
| `附表D_支撑轴力等监测日报表` | 同上（单位 kN） |
| `附表E_地下水位等监测日报表`（`--tables cdef` 时） | `初始高程｜本次高程｜上次高程｜本次变化｜累计变化｜变化速率｜编号｜点号｜备注` |
| `附表F_裂缝监测日报表`（`--tables cdef` 时） | `长度(mm)｜宽度(mm)｜本次测试值｜单次变化｜累计变化｜变化速率｜点号｜形态｜备注` |

- 抬头 5 行（第 3 行：表 C / E **含天气**，表 D / F **不含**）；
- 数据行（每测点保留 `--appendix-periods` 期，默认 3）；
- 页脚：`工况描述：` / `简要分析及判断性结论：`（表 F 为「当日监测的…」）/ `工程负责人：…监测单位：…` / `第 页 共 页`；
- 数据区之后再接 `简要分析及判断性结论` 统计块（测点数、末次等级统计、红色/黄色清单、
  速率较大测点、`结论：…`）。
- 「备注」= `预警等级：…；报警值：…；占报警值：…%；超报警值：…`；
  输入已带则**原样引用**（含原文单位），否则取内置判据库区间下限。

- `--split` 时每张附表**另存为一个单独文件**（`<output>_附表C.xlsx` …）。
- 「备注」除判定信息外，还会叠加**速率口径判据**的触发理由与依据条款（见下）。

> **实测一致率**：以参考工作簿自身为输入重新生成 ——
> 附表 C + D 数据区 **168 格 / 0 差异 / 100.0%**（默认）；附表 C/D/E/F 共 **303 格 / 0 差异 / 100.0%**（`--tables cdef`）。
> 完整规范见 `references/05_附录CDEF表式规范.md`。

### 速率口径判据（三种形态统一生效）

> 来源：同事在同类 skill 开发中踩过的坑 ——「只取末次读数掩盖日内变化」「日平均速率掩盖突变」。

| 判据 | 依据 | 触发条件 | 等级 |
|---|---|---|---|
| 连续超 70% | **GB 50497-2019 第 8.0.3 条** / 表 8.0.4 注 | 变化速率**连续 3 次** ≥ 速率限值 × 70% | 至少 **橙色预警** |
| 突然明显增大 | **GB 50497-2019 第 8.0.9-1 条**（强制性条文） | 本次变化量 ≥ **3 倍**前 3 期变化量**中位数** | **红色预警**（危险报警） |

- **只升不降**；触发理由与依据条款写入「备注」。
- **亚日级序列主动弃权**：采样间隔 < 1 天（如 5 分钟级）时序列由噪声主导，两条判据均不适用。
- **期次不连续（序列含空缺）拒绝判「连续」/「突变」**。
- 「突变倍数」规范**未定量**，默认 3.0，属**工程经验判据**，须由项目专项监测方案确认。

**确认机制（安全阀）**：运行时脚本会**先在控制台打印醒目提示块**，说明该判据规范未定量、
当前倍数、以及须由项目专项监测方案确认；**未确认时该条不参与判定**（流程不中断、退出码为 0），
仅在产物中注明「突变判据未确认，已停用」。确认后加 `--ack-sudden-factor`
（或设 `EXCAVAGUARD_ACK_SUDDEN_FACTOR=1`）才真正启用。

| 状态 | 判据是否生效 | 产物中的体现 |
|---|:--:|---|
| 默认（未确认） | ✗ | 本会触发的行：备注加「突变判据未确认，已停用（…；加 --ack-sudden-factor 后启用）」；说明页/汇总页同步声明 |
| `--ack-sudden-factor` | ✓ | 触发时升级为**红色预警**，备注注明依据条款与阈值 |
| `--sudden-factor 0` | ✗ | 彻底关闭，**不打印提示、不留痕** |
| `--rate-rules off` | ✗ | 两条速率判据全部关闭 |

### 日内极值提示（只取末次读数会掩盖日内变化）

`cd` 形态的「汇总」页新增 **「二·补充、日内极值提示」**：聚合到「日」时同时保留当日极值
（`day_min` / `day_max` / 观测条数），当 `当日极值摆动 > 2 × |本期变化量|` 时列出该测点，
提示日报口径可能低估日内实际波动。

## 执行流程

1. **确认输入**：检查 `--input` 存在；若是目录，列出将读取的文件。
2. **读取**：脚本自动探测编码（utf-8-sig / utf-8 / gb18030 / gbk / big5 / latin-1）、
   分隔符，并在**前 12 行内定位真实表头**（跳过标题行与空行）。
3. **清洗**：列名映射 → 时间解析 → 单位归一 → 项目归类。
4. **聚合**：按 `(测点, 日期)` 取当日**最后一次观测**（日报表以「日」为最小期次）。
5. **派生**：
   - 上次测值 = 目标期的**前一期**（无前一期则等于本期）
   - 本次变化 = 本次测值 − 上次测值
   - 累计变化 = 本次测值 − 该测点**最早一期**测值
6. **写表**：
   - `--layout cd` → 生成 `表C` / `表D` / `汇总`。
   - `--layout verdict` → 载入内置判据库 → 解析各监测项的生效限值 →
     取知识库命中（缓存优先）→ 判定等级 → 生成 `表C判定汇总` / `表D判定汇总` / `说明`。
   - `--layout af` → 按 `(来源, sheet, 点号)` 分组、保留最后 N 期 → 生成
     `附表C` / `附表D` / `附表E` / `附表F` 四张原表式 sheet（`--split` 时另存单表文件）。
7. **报告**：`--report` 时输出清洗与判定报告 JSON。

### 命令行

```bash
# 形态一：规范表式（表 C / 表 D）
python scripts/fill_summary_table.py \
  --input  <数据文件或目录> \
  --output <输出.xlsx> \
  --meta   meta.json \
  [--date 2026-10-07] \
  [--limits limits.json] \
  [--report report.json]

# 形态二：判定汇总表（独立文件）
python scripts/fill_summary_table.py \
  --input  <数据文件或目录> \
  --output <判定汇总表.xlsx> \
  --layout verdict \
  [--meta meta.json] [--design design.json] \
  [--period interval|daily] [--safety-level 一级] \
  [--rag auto|off|refresh]

# 两者同时产出
python scripts/fill_summary_table.py \
  --input <数据> --output <汇总表.xlsx> --layout both \
  [--verdict-out <判定汇总表.xlsx>]

# 形态三：附录 C/D/E/F 原表式（可直接吃附录表式工作簿）
python scripts/fill_summary_table.py \
  --input  <数据文件或目录> \
  --output <附录表式.xlsx> \
  --layout af [--appendix-periods 3] [--derived-note auto|always|never]

# 形态三 + 每张附表单独提取（默认只提取 附表C / 附表D）
python scripts/fill_summary_table.py \
  --input <数据> --output <附录表式.xlsx> --layout af --split

# 需要附表 E / 附表 F 时
python scripts/fill_summary_table.py \
  --input <数据> --output <附录表式.xlsx> --layout af --tables cdef

# 关闭速率口径判据（回到纯累计量判定）
python scripts/fill_summary_table.py --input <数据> --output <出.xlsx> --layout af --rate-rules off

# 三种形态一起出
python scripts/fill_summary_table.py --input <数据> --output <主输出.xlsx> --layout all
```

## 形态一的预警等级处理口径（表 C / 表 D sheet）

> 本节只适用于 `--layout cd`。`--layout verdict` 走**内置判据库 + 知识库**的判定链路
> （见「形态二」与 `references/04`）。

按优先级：

1. **输入数据自带「预警等级」列** → **原样引用**（与示例汇总表「原样引用填报值」的口径一致）
2. **显式提供 `--limits`** → 按累计值 / 变化量限值判定（**可选增强，默认不启用**）
3. **否则** → `未判定(待复核)`

`--limits` 的格式：

```json
{
  "支撑轴力":   {"warn": 800, "control": 1000, "rate": 120},
  "锚杆轴力":   {"warn": 300, "control": 400,  "rate": 40},
  "土压力":     {"warn": 60,  "control": 80,   "rate": 4},
  "孔隙水压力": {"warn": 50,  "control": 70,   "rate": 4},
  "围护墙内力": {"warn": 400, "control": 500,  "rate": 20}
}
```

判定规则（仅在提供 `--limits` 时）：

| 条件 | 等级 |
|---|---|
| `\|累计变化\| ≥ control` 或 `\|本次变化\| ≥ rate` | 红色预警 |
| `\|累计变化\| ≥ warn` 或 `\|本次变化\| ≥ rate` | 橙色预警 |
| `\|累计变化\| ≥ warn × 70%` | 黄色预警 |
| 均不满足 | 正常 |

> ⚠️ **阈值必须来自项目专项监测方案**（GB 50497-2019 第 8.0.1 条规定预警值由设计方确定）。
> 本 Skill 内置的任何示例阈值**都不是规范判据**，仅供流程演示。

## 失败与弃权边界

| 情形 | 处理 |
|---|---|
| 输入文件不存在 / 类型不支持 | 退出码 2，明确报错 |
| 编码无法识别 | 记入读取报告错误，该文件跳过 |
| 表头未识别 | 该 sheet 跳过，记入读取报告 |
| 测点号缺失 | 该行不写入，记入**待复核** |
| 监测项目不属于表 C/D/E/F | 该行不写入，记入**待复核**（表 A / 表 B 会注明「不在本 Skill 处理范围」） |
| 附录表式：无监测项目列且点号前缀未匹配 | 该行不写入，记入**待复核**，**不猜测监测项目** |
| 时间无法解析 | 该行写入表内但数值列填 `—`，预警等级 `未判定(待复核)` |
| 单位无法识别或量纲不符 | 同上 |
| 测值缺失 / 非数值 | 同上 |
| `本次变化` 与 `本次测值 − 上次测值` 不一致（>0.5） | 写入备注提示核对，等级 `未判定(待复核)` |

判定汇总表（`--layout verdict`）追加的弃权边界：

| 情形 | 处理 |
|---|---|
| 内置判据库未收录该监测项（如「立柱内力」） | 报警值/控制值/等级 = `未知`，I 列退化为 `RAG命中 GB50497-2019` |
| 限值为设计值占比但未提供 `--design` | 报警值/控制值以占比文本展示，等级 = `未知` |
| 知识库未接入 / 未命中 | J 列注明「未接入知识库，未做 RAG 命中」，**不补造条文** |
| 知识库命中相关度低或文本为 OCR 噪声 | 照实引用规范名 + 条文号 + 相关度；命中摘要原样放入「说明」页，不作改写 |

**硬约束**：

- **不插值、不补造数据**：缺失一律填 `—`（全角破折号），并在备注说明。
- **不代填签署栏**：工程负责人 / 监测单位 / 编制 / 审核 / 签发一律留 `＿＿＿＿`。
- **`未判定(待复核)` / `未知` 表示弃权，不是「安全」**，必须转人工复核，禁止渲染为正常项。
- **不臆造规范表号、条文号、页码或来源**：知识库未命中时如实注明。
- **不做风险判定与预警发布**：仅整理数据与判定辅助，结论与处置由责任人员负责。
