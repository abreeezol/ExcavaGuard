# 附录 C / D / E / F 原表式规范（`--layout af`）

> 版式来源：`监测日报_附表AF_RAG.xlsx` 中的 附表C / 附表D / 附表E / 附表F。
> 本文件描述该表式的**逐行锚点、逐列定义、备注口径、输入识别规则**，
> 以及本 Skill 输出与之的**实测一致率**。

---

## 1. 与「示例汇总表式」的区别

本 Skill 有三种输出形态，对应两套**不同**的表式：

| 形态 | 表式 | 抬头 | 组号/点号位置 | 预警等级位置 |
|---|---|---|---|---|
| `cd` | 示例汇总表式 | 标题 + 5 行抬头（第 8 行为表头） | **最前** | 独立列 |
| `verdict` | 判定汇总表（10 列） | 无抬头，第 1 行即表头 | 第 2 列 | 独立列 |
| **`af`** | **GB 50497 附录原表式** | **5 行抬头，第 6 行为表头** | **末尾** | **内嵌在「备注」里** |

`af` 形态严格对齐 `监测日报_附表AF_RAG.xlsx`，也是**唯一支持表 E / 表 F** 的形态。

## 3. 表头（第 6 行）与数据列

### 表 C / 表 D（8 列）

```
深度(m) | 本次测值 | 上次测值 | 本次变化 | 累计变化 | 组号 | 点号 | 备注
```

- **表 C**（围护墙内力、立柱内力、土压力、孔隙水压力）→ 单位 **kPa**
- **表 D**（支撑轴力、锚杆轴力）→ 单位 **kN**

### 表 E（9 列）

```
初始高程 | 本次高程 | 上次高程 | 本次变化 | 累计变化 | 变化速率 | 编号 | 点号 | 备注
```

监测项目：地下水位、周边地表竖向位移、土体分层竖向位移、坑底隆起（回弹）。单位 **mm**。

### 表 F（9 列）

```
长度(mm) | 宽度(mm) | 本次测试值 | 单次变化 | 累计变化 | 变化速率 | 点号 | 形态 | 备注
```

监测项目：裂缝。单位 **mm**。

### 3.1 「备注」列口径

```
预警等级：{等级}；报警值：{限值文本}；占报警值：{百分比}%；超报警值：{是/否}[；本次变化量/变化速率由累计序列推算]
```

- **等级写法**（与参考文档一致）：`正常` / `黄色(需关注)` / `橙色(预警)` / `红色(报警)` / `未判定`
- **报警值**：输入「备注」里已带 → **原样引用**（含原文单位，如 `112 kN·m / kPa`、`25 mm / m`）；
  否则取内置判据库区间下限（如 `480 kN`）。
- **占报警值** = `|累计变化量| ÷ 报警值 × 100`；输入已带则原样引用。
- **超报警值** = `占报警值 ≥ 100%` 时 `是`，否则 `否`。
- **末端来源说明**：参考文档在**所有**附表备注末尾固定追加「本次变化量/变化速率由累计序列推算」。
  本 Skill 由 `--derived-note` 控制：

  | 取值 | 行为 |
  |---|---|
  | `auto`（默认） | 仅在**确实由序列推算**（输入未提供变化速率）时追加 —— 更严谨 |
  | `always` | 所有附表都追加 —— 与参考文档**逐字节一致** |
  | `never` | 不追加 |

### 3.2 「组号」/「编号」列

- 输入**带该列** → 原样引用（参考文档为 `—`，输出即 `—`）；
- 输入**无该列** → 按监测项目自动归类：`1` = 表 C 族、`2` = 支撑轴力、`3` = 锚杆轴力。

### 3.3 「简要分析及判断性结论」小节（数据区之后）

```
· 本附表共 N 个测点（{家族名}），监测期 {起} ~ {止}
· 末次监测日统计：正常 a 点、需关注(黄色) b 点、报警(红色) c 点、未判定 d 点
· 红色报警测点（累计量已达/超报警值）：{点号} 累计 {值} / 报警值 {值}；…
· 需关注(黄色)测点（累计≥报警值 70%）：…
· 变化速率较大（≥2 单位/天）的测点：{点号} {速率}、…
结论：…
```

## 4. 输入识别规则（`--layout af` 能直接读参考文档的原因）

参考文档用的是**附录原表式**，与长表/宽表都不同。本 Skill 为此新增了三项识别能力：

### 4.1 表头定位

在**前 12 行内**按「已知列名命中数」定位表头。附录表式的表头在第 **6** 行，
命中 `深度(m)` / `本次测值` / `上次测值` / `本次变化` / `累计变化` / `组号` / `点号` / `备注`
等 8 个已知列名，可稳定命中。

### 4.2 监测项目反推（关键）

附录表式**没有「监测项目」列**。当该列缺失时，按 **测点号前缀** 反推：

| 前缀 | 监测项目 | 表 |
|---|---|:--:|
| `CK` | 孔隙水压力 | C |
| `CL` | 立柱内力 | C |
| `CN` | 围护墙内力 | C |
| `CT` | 土压力（围护墙侧向） | C |
| `DM` | 锚杆轴力 | D |
| `DN` | 支撑轴力 | D |
| `EB` | 坑底隆起（回弹） | E |
| `ES` | 周边地表竖向位移 | E |
| `EW` / `SW` | 地下水位 | E |
| `FC` | 土体分层竖向位移 | E |
| `DBC` | 周边地表竖向位移 | E |
| `KB` | 坑底隆起（回弹） | E |
| `F` | 裂缝 | F |
| `TY` / `KL` / `QN` / `LZ` / `ZL` / `MG` | CD_data 模拟数据集 | C / D |
| `A-DP` / `A-SH` | 水平位移 | A（**不在处理范围**） |
| `B-DP` / `B-SH` | 深层水平位移 | B（**不在处理范围**） |

前缀按**长度降序**匹配（`DBC-01` 先匹配 `DBC` 而非 `D`）。推不出 → 记入待复核，不猜测。

### 4.3 备注解析与页脚跳过

- 从「备注」中正则抽取 `预警等级：…`、`报警值：…`、`占报警值：…`，作为输入自带的判定信息**原样引用**；
- 页脚行（`工况描述：` / `简要分析…` / `工程负责人` / `第 页` / `结论：` / `·` 开头）**自动跳过**，
  不计入待复核；
- 非记录表 sheet（名称含 `超限` / `清单` / `说明` / `汇总`，或独立的 `监测日报` 文字页）**整表跳过**，
  并在读取报告中列出。

## 5. 期次口径

| 情形 | 取法 |
|---|---|
| 组内有可解析时间 | 先按日聚合（当日最后一次观测），再取**最后 N 期** |
| 组内无时间（附录 E / F 常无日期列） | 直接取**最后 N 条**（保持文件内顺序） |

`N` = `--appendix-periods`，默认 **3**（与参考文档一致）。

派生规则（输入已自带时以输入为准）：

| 字段 | 派生 |
|---|---|
| 上次测值 | 组内前一期；**首期等于本期** |
| 本次变化 | `本次测值 − 上次测值` |
| 累计变化 | `本次测值 − 组内首期测值` |
| 变化速率 | `本次变化 ÷ 间隔天数` |

## 6. 实测一致率（反向验证）

用参考文档自身作为输入，重新生成 附表C / 附表D / 附表E / 附表F 并与原文**逐单元格**比对：

| 附表 | 数据行 | 比对 |
|---|:--:|---|
| 附表C_围护墙内力等 | 15 | 一致 |
| 附表D_支撑轴力等 | 6 | 一致 |
| 附表E_地下水位等 | 9 | 一致 |
| 附表F_裂缝 | 6 | 一致 |
| **合计** | **36** | **303 格 / 0 差异 / 一致率 100.0%** |

> 比对命令（`--derived-note always` 时达到 100%；默认 `auto` 时仅备注末端来源说明有 15 格差异，
> 因为本 Skill 只在**确实推算**时声明来源，比参考文档更严谨）。

## 7. 边界声明

1. 本表式为 GB 50497-2019 附录 A~G 的**表 C / D / E / F** 原表式；表 A / 表 B 不在本 Skill 处理范围，
   其数据行会被明确记入**待复核**并注明「不在本 Skill 处理范围」，**不静默丢弃**。
2. 签署栏（工程负责人 / 监测单位 / 编制 / 审核 / 签发）一律留 `＿＿＿＿`，**不得代填**。
3. 缺失值填 `—`（全角破折号），**不插值、不补造**。
4. `未判定` / `未知` 表示**弃权，不是「安全」**，必须转人工复核。
5. 判定阈值以**项目专项监测方案**为准（GB 50497-2019 第 8.0.1 条）；本表不作预警发布。
