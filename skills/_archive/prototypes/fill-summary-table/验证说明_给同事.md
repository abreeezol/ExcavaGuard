## 4. 需要你重点确认的两个口径点

1. **「突然明显增大」判据（GB 50497-2019 第 8.0.9-1 条，强制性条文）**
   规范**未给出定量阈值**。本 Skill 按「本次变化量 ≥ **3 倍**前 3 期变化量中位数」判定，
   **属工程经验判据**。为安全起见**默认不生效**，运行时会在控制台打印醒目提示；
   确认后加 `--ack-sudden-factor`（或设环境变量 `EXCAVAGUARD_ACK_SUDDEN_FACTOR=1`）才启用。
   → **请确认这个 3 倍阈值是否符合你们的项目专项监测方案。**
2. **预警等级口径**：本 Skill 用「正常 / 黄色 / 橙色 / 红色 / 未判定（未知）」四级 + 弃权。
   若你们项目统一用三级（正常 / 需关注 / 报警），需要先确认再做映射。

## 5. 已知边界（不是缺陷）

- **表 A（水平位移、竖向位移）、表 B（深层水平位移）、表 G（巡视检查）不在处理范围**，
  其数据会被记入待复核并注明，不做静默丢弃。
- **`未判定` / `未知` = 弃权，不是「安全」**，必须转人工复核。
- **不插值、不补造数据**：缺失一律填 `—`；签署栏一律留 `＿＿＿＿`。
- **判定阈值以项目专项监测方案为准**（GB 50497-2019 第 8.0.1 条：预警值由设计方确定）。
- 亚日级序列（采样间隔 < 1 天）**主动弃权**速率口径判据 —— 噪声主导，判了也不可信。
- `assets/rag_hits.json` 内的 `rag_dir` 字段是生成时的本机路径，**纯信息字段、不影响运行**。
