# 相似案例检索

## 触发条件

- 已有异常事实，需要检索相似工程、施工阶段或响应特征作为经验参考。
- 工况归因需要案例证据、差异项和相似度。
- 不用于改变阈值、超限状态或生成确定性事故结论。

## 输入

- `query`：案例检索文本，建议包含支护形式、土层、地下水、施工阶段、监测类型、异常方向和变化速率。
- `minimum_score`：可选最低匹配分数，默认 0.1。
- `limit`：可选候选数量，默认 3。
- 运行上下文必须配置案例检索器。

## 输出

成功时返回：

- `cases`：案例列表，每项含 `id`、`summary`、`metadata`、`similarity`、`matched_terms` 和 `limitations`；
- `notice`：案例仅供经验参考，不得改变阈值或超限事实；
- `trace`：查询、最低分数、命中数量和证据 ID。

## 执行流程

1. 确认案例检索器可用。
2. 依据结构化工程特征组织检索查询。
3. 执行召回并按 `minimum_score` 过滤。
4. 返回相似条件、差异限制、分数和来源标识。
5. 将结果交给工况分析 Skill，保持案例证据与规则判定分离。

## 失败与弃权边界

- 未配置检索器：以 `EVIDENCE_NOT_FOUND` 弃权。
- 查询或数值参数无效：以 `INVALID_INPUT` 弃权。
- 无候选达到最低分数：以 `EVIDENCE_NOT_FOUND` 弃权，并说明不能给出案例归因。
- 来源不明、关键特征缺失或案例互相冲突：停止确定性归因，要求人工复核。
- 不以案例覆盖规范要求，不把相似性当作因果性，不隐去差异项。
