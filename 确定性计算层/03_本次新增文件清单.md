## 二、本轮新增文件（阶段语义修正）

### 2.1 阶段一 · 数据准备

| 文件 | 职责 | 要点 |
|---|---|---|
| `pipeline/stage1_data_preparation/ingest.py` | 把用户上传数据与模拟数据统一接入并归一化 | 单位换算（mm/cm/m、kPa/MPa、kN/N/MN）、6 种日期格式解析、来源标识 `real / simulated / unknown`、无法归一化的字段原样保留并挂标记 |
| `pipeline/stage1_data_preparation/quality_scan.py` | 噪音与缺失识别 | 14 类问题码；**只识别不修改**，原值一律保留；真实/模拟分开统计 |
| `pipeline/stage1_data_preparation/robustness_simulator.py` | 健壮性验证用噪声注入 | 7 种噪声预设；输出强制 `data_origin="simulated"` + `source_dataset` 溯源；`robustness_report()` 对比注入量与识别量 |

| 文件 | 职责 | 要点 |
|---|---|---|

### 2.3 阶段三 · 规范比对

## 五、日报模块接口契约

**本层不生成日报文件。** 日报正文、版式、结论与建议措辞由后续独立 Agent 实现；
本层只保证交接载荷完整、可校验、可追溯。

| 文件 | 作用 |
|---|---|
| `pipeline/orchestrator.py` → `build_daily_report_input()` | 产出 `excavaguard.daily_report_input/v1` 载荷 |
| `contracts/daily_report_input.schema.json` | 机器可读契约（JSON Schema 2020-12），字段只增不改 |
| `tools/validate_daily_report_input.py` | 契约校验工具，消费方可前置校验（`--self-test` 可自检） |
| `04_日报模块接口契约.md` | 字段语义、消费约定、稳定性规则 |
| `05_参数查漏与补充分析.md` | 对照参数清单查漏、补充参数统计画像、流水线接入改动 |
| `06_上传数据到风险识别链路_目标实现度评估.md` | 目标实现度评估、关键差距（P0/P1）、风险点汇总 |

`standards_sources` `data_quality` `summary` `alerts` `review_queue` `items`
`disclaimer` `note`。

实跑校验结果（`tools/run_combined_real_and_simulated.py`）：
