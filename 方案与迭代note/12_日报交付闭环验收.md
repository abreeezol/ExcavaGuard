# 本地日报交付闭环验收

日期：2026-10-14。需求范围与设计见 `spec.md`、`框架demo.md` §十二。

## 已实现

- 输入、冻结结果、Agent 检查点、失败和复核决定保存在 `var/runs/`，修订不可变。
- 历史与详情、原预算内显式续跑、人工接受/退回/拒绝 API 已接通。
- `/workbench` 默认显式生成并审计三件套，可恢复历史、展开三 Agent 轨迹、
  下载、提交理由和加载原输入建立关联重跑。
- 单操作者密码会话和单项目隔离；开发默认绑定 localhost，生产缺配置则拒绝业务接口。
- 下载绑定当前持久化审计清单并重新核对文件指纹。人工接受不等于签发。

  1 项 Supabase Provider live 按配置跳过。

  Python 临时物化、运行 revision CAS、三件套私有下载、人工接受、云端篡改阻断及清理。
- `tests/persisted-runs.test.ts`：12 项，覆盖磁盘恢复、不可变修订、并发冲突、损坏、
  跨项目隔离、旧草稿、重复复核、接受、退回、拒绝、文件修改和密码会话。
- `tests/agent-executor.test.ts`：5 项，包括检查点续跑、存储失败不误判为能力失败、
  原截止时间不重置。Python 判定引擎没有改动。
- 真实 85 通道宽表：上传、当日 85 条载荷、A～F 附表、无 G、审计、下载、落盘恢复和接受
  全链通过；接受前后 payload 完全一致。

  退回关闭下载、恢复输入、补充底板日期后的关联重跑、Supervisor/报告/审计轨迹、
  Excel 下载和接受记录。所有人工决定注明仅为自动化验收样例。

  关联运行的父 ID 和补充工程条件保持一致。
- 缺少飞书 PRD 和 Lume feature，Guardian 的 PRD 用例生成不适用本次独立本地任务；
  本报告不声称通过 Guardian 门禁。需求依据为对话、spec 和仓库契约。

## 代码复查与修正

按 code-reviewer 检查新增代码的空值、类型、异常、资源释放及重复操作边界。

| 问题 | 实现位置 | 修正与依据 |
| --- | --- | --- |
| 非法运行 ID 的错误被存储异常包装覆盖 | `src/server/storage/run-store.ts` | 在文件访问 try 之前验证 ID，非法输入稳定返回 400；边界测试通过 |
| 上传索引并发覆盖或损坏被视为空索引 | `src/server/storage/monitoring-file-store.ts`、`atomic.ts` | 文件锁、完整临时文件、原子替换；损坏明确报错；并发上传不丢记录 |
| 历史切换可能改变关联重跑的父运行 | `src/app/workbench/workbench-client.tsx` | 父运行 ID 单独冻结；浏览器重跑记录保留正确关联 |
| 检查点故障可能被误标为报告能力异常 | `src/server/agents/executor.ts` | 存储回调在能力执行异常捕获范围之外；专门回归通过 |
| 轨迹缺少 Supervisor 路由及真实调用时间 | `src/server/agents/executor.ts` | 路由进入版本化轨迹，能力调用保留实际起止时间 |
| 更换密码或项目后旧会话仍可能有效 | `src/server/access.ts` | 会话签名绑定密码与项目配置 |
| 隐藏监测文件输入无法通过键盘直接访问 | `src/app/globals.css`、`workbench-client.tsx` | 使用可见且有可访问名称的文件输入，浏览器原生上传通过 |
| 构建依赖追踪误包含运行数据 | `next.config.ts`、`run-store.ts` | 排除 var、环境文件和临时验收目录；运行记录仍由运行时挂载提供 |
