# 第一性原理：从监测输入到可复核报告

更新日期：2026-11-05。本轮保留三Agent主体及适配器体系，改进事实交接边界；未推送。

## 要解决的最小业务问题

把指定工程、指定周期的观测转成工程师可复核的报告草稿。必须能够回答：用了什么原始数据，按什么条件与规则计算，结论有哪些依据，哪些内容还不能确认。完成标准包括计算、依据、审查状态与人工决定，不能只以“生成了文件”判断成功。

## 统一主流程

```text
授权工程与保存参数
  → ① 场景适配与判据匹配
  → ② 确定性计算、规则判级与事实冻结
  → Supervisor规划、规范查证及受控追加分析
  → 报告Agent组织证据、编写草稿与回应意见
  → 审计Agent执行文件核验与独立模型语义审查
  → 工程师接受、退回或拒绝
```

①加载专业适配器、工程参数、适用规范目录及已确认规则版本。②使用完整历史计算，再选取报告周期，执行明确规则并冻结原始来源、结果、未知项及辅助资料。迁移时专业差异放适配器；权限、存储、时序编排、事实交接、Agent状态机、通用审计与人工反馈继续复用。

三Agent前的两板块属于通用执行服务，由适配器提供专业能力；它们不整体归属于某个适配器。规范库也不是计算规则库。

## 按不可替代的职责分工

| 责任方 | 负责 | 约束 |
|---|---|---|
| 程序与专业适配器 | 参数校验、计算、结构化规则执行、版本与来源留痕 | 缺条件或判据则披露未知，不能让模型补数值 |
| Supervisor | 根据冻结结果选择查证重点、组织检索及有限追加分析 | 规范基础覆盖由程序强制执行，最多三项定向查证，不重判冻结等级 |
| 报告Agent | 将监测、规范及工况证据组织成解释与建议，逐项回应工程师意见 | 不改原始数据和判级，不据相关性认定因果 |
| 审计Agent | 调用文件校验Skill，独立审查模型段落的依据与表达 | AI模式两层审查均完成才允许完整通过，故障不能写成通过 |
| 工程师 | 确认专业规则变更、复核报告及现场处置判断 | 系统内接受不等同正式工程签发 |

三个角色的价值分别在于任务取舍、证据表达、独立质疑。数值计算不需要增加模型角色。规则变更分析复用现有角色，作为项目配置任务执行，不增加第四个常驻Agent，也不在每日报告中重复要求用户确认。

## RAG与数值判据的两条路径

- 日常报告：Supervisor阶段开展适用规范目录及专题检索，对持续预警扩大检索；检索结果冻结为证据，供编报和审计共同使用。RAG候选未命中不自动否定已有可追溯数值规则；候选命中也不自动成为执行规则。
- 新上传要求：项目独立知识库 → 模型辅助提取候选 → 程序校验原文、单位、条件和影响 → 工程师集中确认及有权限角色发布 → 下一次计算加载规则版本。未发布内容仍只能作为检索证据。

当前补充执行器仅覆盖明确的正向mm/mm/d固定阈值。公式、区间、频率与复杂条件不能宣称已自动适配。隧道已有独立规范候选库与四类变形测项，但完整的规范数值默认判据仍需逐项专业适配和核验。

## 本轮落实的事实一致性优化

实现：`src/server/preparation/fact-integrity.ts`、`src/server/preparation/pipeline.ts`、`src/server/agents/executor.ts`。

1. 抽离轻量事实完整性模块，准备层和Agent执行层共用规范化SHA256及交接校验，不让执行器依赖整个数据准备流程。
2. 三Agent直接使用冻结载荷中的辅助资料。平行参数可兼容传入相同资料，任何替换或冻结后追加均拒绝；调用方省略平行参数时仍能恢复原辅助资料。
3. 新运行接收事实副本；保存检查点时再提供状态副本，阻断调用方与保存回调意外改写事实。
4. 新运行与续跑入口核对快照指纹；每次保存检查点前再次核对。续跑不得传入不同原始载荷或不同辅助资料，已有辅助资料检查点也必须与冻结载荷一致。
5. 历史载荷无准备摘要仍兼容，但Agent快照自身的内容指纹仍须一致。

这是应用层一致性校验，不是数字签名。拥有存储写权限的人若同步重算所有指纹，此机制不能证明防篡改；它也不证明原始数据真实或专业判据正确。

## 验收与后续衡量

新增测试覆盖辅助资料替换、引用隔离、键顺序稳定性、旧格式快照损坏、损坏续跑提前拒绝及辅助资料自动恢复。完整回归结果记录在update.md。

后续评价按固定样例记录：计算/判级预期命中率、未知项披露、规范目录查询覆盖、引用可定位率、意见回应完成率、首次双层审查通过率、端到端耗时和模型调用量。测试样例必须标注模拟/真实来源及工程师确认状态；软件测试通过不能代替工程师认可。

未完成重点：工程师确认的规则及报告评价集、隧道更多监测量及规范判据、复杂新规则适配、真实工况效果与稳定耗时评价。当前不以增加Agent数量或导入PDF数量作为智能化效果指标。

本轮真实模型复验：隔离测试工程、模拟监测数据，经上传、两前置板块、规范检索、三角色模型调用及双层审查，1项通过，测试总耗时约19.2秒。此为单次样例，不作为生产性能指标或专业验收。最终执行器与边界专项35项通过。
