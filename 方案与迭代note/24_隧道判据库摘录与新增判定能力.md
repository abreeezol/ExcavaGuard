## 4. 新增的三项判定能力

### 4.1 断面级综合判定（`stage3_standard_comparison/section_judge.py`）

- 按**显式**「测点→断面」映射归组（`points_meta[pid].section_id` 或 `options.section_map`），**不按点号前缀猜断面**；未归属的单独列 `unassigned`。
- 断面等级 = 同断面所有条目**取最不利**（五级排序）。
- 完整性否决：同断面缺必测项（拱顶沉降、净空收敛 —— GB 50911 表4.2.3 一~三级均为√），或存在"未知"条目时，**断面不得判为正常**，降为「未知」并写明缺什么。
- 载体：载荷新增顶层 `sections`（可选字段，非断面场景为 null），每断面含 `worst_level / worst_item / completeness / incomplete_reasons`。

### 4.2 收敛稳定 / 可停测（`stage3_standard_comparison/convergence.py`）

- 阈值与连续期数全部来自判据库：`stability_criterion.rate_mm_per_day = 0.2`（JTG/T 3660-2020 18.6.3-2"速率小于0.2mm/d 时围岩达到基本稳定"），连续 3 期为系统最小样本（**规范未规定期数，已在 note 显式声明**）。
- 期数不足 → `insufficient`，不因"最近几期都小"就推断稳定。
- 同时给出**速率分档**（18.6.3-2）：>1.0 急剧变形／0.2~1.0 缓慢变形／<0.2 基本稳定。
- 结论措辞只回答"是否满足规范给出的量化条件"，**停测决定权在工程师**。

### 4.3 位移管理等级（表 18.6.3 口径）

- `U<U0/3 可正常施工`、`U0/3≤U≤2U0/3 应加强支护`、`U>2U0/3 应采取特殊措施`。
- U0 = 设计极限位移（一般取设计预留变形量）。**缺 U0 时不猜**：不输出等级，打 `MGMT_LEVEL_NOT_EVALUATED` 标记并写明缺什么。
- 与五级风险分级**并列展示、互不替代**（五级是本系统统一口径，管理等级是规范原文分档）。

## 5. 需要你知道的三处判断

1. **五级分级的档位（0.5/0.7/1.0/1.2）是本系统统一口径**，不是隧道规范原文。隧道规范给的是"U/U0 三档"和"速率三档"，两者都在结果里并列给出。若你希望隧道改用 1/3、2/3 作为预警阈值，这是一处配置改动，需要你确认。
2. **规范明确"控制值应由设计文件明确"**（GB 50911-2013 第 9.2.1、9.2.2、9.2.3 条均有此前提），本库取的是"无地方经验时"的表格值。实际工程若有设计文件/专项方案，应当上传并按字段覆盖，本库值只能作兜底。
3. **表9.2.3-2 三级无车站行**：车站按区间取值会偏松，已在规则 note 里写明"需设计确认"，没有自作主张外推。
