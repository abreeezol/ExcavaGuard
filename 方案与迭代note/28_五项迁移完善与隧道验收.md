## 盾构计算与规范

支持累计沉降或带基准高程的数据，统一为mm；速率按真实间隔计算，单位mm/d。工程师确认的项目控制值才用于判级；缺项、未确认、未知测项及未配置隆起控制值明确待核，不补造全国统一阈值。演示12mm等控制值仅为模拟项目参数。

三本原始扫描规范200页经本地离线OCR建立独立SQLite候选库，共194条候选。检索采用全文关键词排序，**不是向量训练**。保留PDF页码、名称、版本、原件/索引SHA及OCR待核标识。排除已识别废止条文所在页，并对共享及项目上传的引用执行废止条款过滤。OCR可能有识别误差，引用须核对原页及适用条件。

规范有效性依据：[住建部2022年第110号公告](https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2024/art_17339_767715.html)。不能把旧标准整本一概视为全部有效。

## 维护命令

使用Linux Node环境运行：`npm run adapter:validate`、`npm run adapter:evaluate`、`npm run adapter:release -- tunnel-shield`。发布目录在var/adapter-releases，`npm run adapter:release -- --verify <目录>`核对归档文件。归档不含密钥或用户资料，不代表签名认证或自动回滚。

本地规范SQLite不进入Git；新克隆部署需在合法取得原始PDF后离线重建或复制经过校验的索引。构建入口`tools/knowledge/build_tunnel.py`，读取工作区“隧道施工相关规范”目录，原PDF保持只读。离线构建额外依赖PyMuPDF、rapidocr-onnxruntime及ONNX运行环境；应用在线检索不运行OCR。部署前检查knowledge-manifest与索引SHA一致。
