# 运行历史单条删除

## 目标与权限

项目管理员可在刷新后的运行历史中单独删除一条记录。复核工程师、工程师和只读成员只能
查看其获授权项目的历史，不能删除项目共享记录。

## 删除契约

客户端调用 `DELETE /api/runs/:id?expected_revision=<revision>`。服务端重新读取当前项目下
的最新运行，校验运行 ID、项目权限和 revision；运行仍处于有效租约时拒绝删除，避免与
正在写入的任务竞争。旧列表上的删除请求返回冲突，要求刷新历史后重试。

## 存储清理

- 本地模式删除该运行的全部 revision 文件，并收集各 revision 的草稿 ID 清理报告目录；
- Supabase 模式删除该运行的全部 revision、报告元数据和 private bucket 对象；
- 删除当前打开记录后，工作台同步清空右侧结果，其他历史和原始上传文件保持不变；
- 云端运行历史已删除但对象清理不完整时，响应返回 `cleanup_complete: false`，界面明确
  提示管理员继续处理残留。

删除不可撤销，不改变其他运行，也不删除被其他运行复用的监测文件和用户规范。
