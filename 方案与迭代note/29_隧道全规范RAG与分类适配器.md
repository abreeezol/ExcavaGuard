# 隧道全规范RAG与分类适配器（2026-11-04）

## 目标与实现

目录“隧道施工相关规范”原有16本PDF全部进入独立隧道知识库。原文件只读，逐页提取/OCR、分块，保存规范名称、编号、PDF页码、原件及片段哈希，构建完成后发布SQLite候选索引。构建工具检查未声明/缺失文件并支持缓存续建。

新增`tunnel-monitoring`适配器，不静默替换旧盾构工程的绑定。登录创建工程时选择“隧道监测适配器（工法分类与独立规范库）”，首次确认工程分类、工法、阶段及特殊地质，之后自动复用。原`tunnel-shield`维持已验收的3本规范范围；基坑库不变。

## 调度与隔离

工程配置 → 解析及周期推荐 → 确定性变形计算/按测项项目控制值核查 → 冻结事实 → Supervisor规划 → 程序逐项检查16本目录的效力和适用范围 → 对符合条件的规范逐本检索并追加主题检索 → 报告Agent → 文件审计和独立语义审查 → 工程师最终确认。

检索器同时强制工程范围，不能通过指定一个不适用规范编号绕过。连续多日预警的补充检索仍受同一范围控制。案例默认工法来自工程配置，不依靠用户重复提示。项目上传同编号规范不能将已废止、效力待核或不适用的公共标准重新升格。新地方规范仍隔离在当前项目。

“全部入库”不等于“全部对所有工程有效”。规范覆盖表明确列出跳过的原因，不把跳过伪装为已查询。当前13本标为有效候选、2本效力更新待核、1本历史废止资料；每个具体工程还会按分类进一步收窄。有效候选仍需核对原页与具体条款适用条件。

## 专业适配

支持地表沉降、建筑沉降、拱顶沉降、净空收敛，分别计算累计变形、单次变化、实际间隔速率及最小二乘趋势。控制值按测项单独确认，未确认或缺失时披露未知。收敛采用向内为正的累计量，高程采用向下为正；原始断面距离不作为累计收敛量。高程基准可复用先前明确基准，同点改变基准拒绝直接计算。

无全国统一数值阈值自动生成。规则公式、专业语义、弃权条件和候选规范映射见适配器`professional-basis.json`，评价输入与预期见`evaluation-fixtures.json`，软件对照结果不等于工程师签认。
