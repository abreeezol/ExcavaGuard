# 数据接入与字段归一约定

## 1. 必需字段与别名

| 标准字段 | 可识别的列名（大小写不敏感） | 缺失处理 |
| --- | --- | --- |
| 测点编号 | 测点编号 / 点号 / 测点 / point_id / point | 整行标记待复核，不参与计算 |
| 监测项目 | 监测项目 / 项目 / 测项 / item | 记为"未注明监测项目"，阈值按测点级或默认匹配 |
| 观测日期 | 观测日期 / 日期 / date / 观测时间 | 该条不参与变化量计算，标记待复核 |
| 观测值 | 观测值 / 本次观测值 / 累计量 / value / 读数 | 保留空值，标记待复核，**不插值填补** |
| 初始值 | 初始值 / 初始读数 / initial | 缺省时视观测值本身为累计量，需在报告中注明该假定 |
| 单位 | 单位 / unit | 无法识别时按 mm 处理并标记待复核 |
| 方向 | 方向 / 正负号 / sign | 缺省按 +1 |

## 2. 日期清洗

支持 `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY.MM.DD`、`YYYYMMDD`、`YYYY-MM-DD HH:MM:SS`。清洗失败保留原字符串并标记待复核，不猜测日期。

## 3. 单位与方向归一

- 位移类统一换算为 **mm**：mm×1、cm×10、m×1000。
- 方向系数：**累计量 =（观测值 − 初始值）× 方向系数**。若数据导出的正负号约定与报告习惯相反，在配置里设 `方向 = -1`，不要改原始数值。
- 轴力（kN）、水位（m）等非位移量不参与 mm 分级，须单独配置阈值。

## 4. 常见数据问题处理原则

| 问题 | 处理 |
| --- | --- |
| 观测值缺失 | 暂停该测点判定，提示补充或复核原始记录；不插值、不用相邻测点代替 |
| 数值格式异常（含文字、单位混入） | 标记待复核，保留原始字符串，不强行转换 |
| 单次变化量 > 3 倍历史变化量标准差且绝对值 > 1 mm | 标记"疑似粗差"，**保留原始值**，不剔除、不平滑 |
| 首期观测（无历史值） | 变化量与速率留空，注明"首期观测" |
| 同测点一天多次观测 | 取当日最晚一条参与计算，其余在备注中说明；不合并求平均 |
| 测点编号一物多名（如 ZCL-1 / ZCL-01） | 建立映射表统一，映射关系写入报告的备注，避免追溯断链 |

## 5. 追溯链要求

每个测点在报告中必须同时可见：**原始观测记录（含行号）→ 计算结果 → 判定阈值与来源 → 报告结论**。任一环缺失即视为待复核，不得跳过。
