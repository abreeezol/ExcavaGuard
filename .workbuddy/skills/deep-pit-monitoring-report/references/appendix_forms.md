# GB 50497-2019 附录 A~G 表式清单（日报格式依据）

来源：《建筑基坑工程监测技术标准》GB 50497-2019 附录 A~G，PDF 存于本 skill `references/GB50497-2019 建筑基坑工程监测技术标准.pdf`（PDF 第 47~54 页 = 标准正文第 40~47 页，扫描件无文字层，需按页看图核对）。

## 表式与适用测项

| 表式 | 名称 | 主表列 | 适用于 |
| --- | --- | --- | --- |
| 表 A | 水平位移、竖向位移监测日报报表 | 点号｜累计位移量(mm)｜本次变化量(mm)｜变化速率(mm/d)｜备注 | 围护墙顶部水平/竖向位移等常规位移测项 |
| 表 B | 深层水平位移监测日报报表 | 深度(m)｜累计位移(mm)｜本次变化量(mm)｜变化速率(mm/d) | 测斜（深层水平位移），按深度分行，右侧附"深度-位移"曲线位 |
| 表 C | 围护墙内力、立柱内力及土压力、孔隙水压力监测日报报表 | 组号｜点号｜深度(m)｜本次测值(kPa)｜上次测值(kPa)｜本次变化(kPa)｜累计变化(kPa)｜备注 | 内力、土压力、孔隙水压力（单位 kPa） |
| 表 D | 支撑轴力、锚杆轴力监测日报报表 | 组号｜点号｜深度(m)｜本次测值(kN)｜上次测值(kN)｜本次变化(kN)｜累计变化(kN)｜备注 | 支撑轴力、锚杆轴力（单位 kN） |
| 表 E | 地下水位、地表竖向位移、分层竖向位移、坑底隆起监测日报报表 | 编号｜点号｜初始高程(m)｜本次高程(m)｜上次高程(m)｜本次变化量(mm)｜累计变化量(mm)｜变化速率(mm/d)｜备注 | 地下水位、周边地表竖向位移、分层竖向位移、坑底隆起 |
| 表 F | 裂缝监测日报报表 | 点号｜长度(本次测试值/单次变化/累计变化量/变化速率)｜宽度(同四项)｜形态 | 裂缝长度与宽度监测 |
| 表 G | 巡视检查日报报表 | 分类｜巡视检查内容｜巡视检查结果｜备注 | 支护结构 / 施工工况 / 周边环境 / 监测设施四类巡视项 |

## 各表共用的表头与表尾字段（表式固定，缺项留空待填）

表头（表 A~F 一致）：

- 第（　）次
- 工程名称 / 报表编号 / 天气
- 观测者 / 计算者 / 校核者
- 仪器型号 / 仪器编号 / 检定有效期
- 本次监测时间 / 上次监测时间

表尾：

- 表内下部：**工况描述：**、**简要分析及判断性结论：**（均为独立单元格，需填写文字）
- 表外下部：工程负责人：　　监测单位：
- 页码：第 　 页 共 　 页

表 G 表头仅保留 工程名称 / 报表编号 / 天气 / 观测者 / 巡视时间，表尾同其他表。

## 日报必备内容（GB 50497-2019 第 9.0.7 条，正文第 39 页 / PDF 第 46 页）

当日报表应包括：

1. 当日的天气情况和施工现场的工况；
2. 仪器监测项目各监测点的**本次测试值、单次变化值、变化速率以及累计值**等，必要时绘制有关曲线图；
3. **巡视检查的记录**；
4. 对监测项目应有**正常或异常的判断性结论**；
5. 对**达到或超过监测预警值**的监测点应有**预警标示**，并有分析和建议；
6. 对巡视检查发现的异常情况应有详细描述，危险情况应有报警标示，并有分析和建议；
7. 其他相关说明。

> **当日报表宜采用本标准附录 A~附录 G 规定的格式。**

配套条款：

- 8.0.1 监测预警值应满足基坑支护结构、周边环境的变形和安全控制要求，**预警值应由基坑工程设计方确定**（→ 阈值必须来自项目设计/专项方案，系统不得自行取值）。
- 8.0.3 变形监测预警值应**包括监测项目的累计变化预警值和变化速率预警值**（→ 阈值配置必须同时提供累计值与速率两类限值）。
- 9.0.1 / 9.0.2 监测技术成果应有相关负责人签字并加盖成果章；监测记录应有相应工况描述、使用正式表格、有相关责任人签字（→ 报告必须留签署栏与工况描述栏，不得代签）。
- 9.0.6 技术成果应包括**当日报表**、阶段性分析报告和总结报告，内容应真实、准确、完整，宜用文字阐述与绘制变化曲线或图形相结合的形式表达。

表 G 巡视检查内容清单（四类，共 29 项）：

- **支护结构**：支护结构成型质量；冠梁、围檩、支撑的裂缝；冠梁、围檩（腰梁）的连续性、有无过大变形；围檩（腰梁）与围护桩的密贴性、围檩与支撑的防坠落措施；锚杆垫板有无松动、变形；立柱有无倾斜、沉陷或隆起；止水帷幕有无开裂、渗漏水；基坑有无涌土、流砂、管涌；面层有无开裂、脱落；其他。
- **施工工况**：开挖后暴露的岩土体情况与岩土勘察报告有无差异；基坑开挖分段长度及分层厚度；侧壁开挖暴露面是否及时封闭；支撑、锚杆是否施工及时；边坡、侧壁及周边地表的排水、截水措施及效果，坑边或坑底有无积水；基坑降水、回灌设施运转情况；基坑周边地面堆载情况；爆破后岩体是否出现松动；吊脚桩支护形式时，岩肩处岩体有无开裂、掉块；其他。
- **周边环境**：管道破损、泄漏情况；围护墙后土体有无沉陷、裂缝及滑移；周边建筑有无出现裂缝、有无发展；周边道路（地面）有无出现新裂缝或沉陷、有无发展；邻近施工（堆载、开挖、打桩、降水）情况；存在水力联系的邻近水体（湖泊、河流等）的水位变化情况；其他。
- **监测设施**：基准点、测点完好状况、保护情况；监测元件及导线的完好情况、保护情况；观测工作条件。

## 生成日报时的落地要求

1. 按测项归入对应表式，一张表只出现同一表式适用的测项；无法归入的测项单独列出并提示核对。
2. 表头字段若用户未提供，**留空待填**（`＿＿＿＿`），不得编造观测者、仪器编号、检定有效期。
3. 表中数值原样引用 `compute_metrics.py` / `parse_appendix_excel.py` 的输出，不重算、不改写。
4. **超限与待复核标识**在附录表式中没有对应列，写入"备注"列，并在表后单独设"集中标识"章节汇总。
5. `组号`、`深度` 等本系统数据源中不存在的字段留 `—`，并在备注中说明需核对原始记录，不得臆造。
6. 附录表式仅规定日报报表格式；预警发布、处置责任仍按既有流程，报告须保留"辅助材料、须经审核签发"的声明。

## 作为输入数据的附录表式 Excel（形态 ①）约定

用户的数据若已是按附录 A~G 表式整理、集中在一个 `.xlsx` 中的成果表，由 `scripts/parse_appendix_excel.py` 解析，约定如下：

1. **结构**：每个 sheet 一张表（sheet 名任意），或一个 sheet 内多张表顺序排列；每张表 = 表头区（第（）次、工程名称、观测者等，可缺）＋ 列头行 ＋ 数据行 ＋ 表尾（工况描述/简要分析/工程负责人，可缺）。列头行按列名特征识别表式（见下），识别不了的表块跳过并在校核问题中说明。
2. **列名识别**：比较时去掉括号内单位、空白与连字符。表 A 看"点号+累计位移"；表 B 看"深度+累计位移"（点号取标题/sheet 名中的孔号，逐深度分行）；表 C/D 看"组号/本次测值+累计变化"，按列头单位（kPa→表C，kN→表D）或标题关键字区分，无法区分标"表CD"并提示待复核；表 E 看"初始高程"；表 F 看"形态+长度/宽度分项"；表 G 看"巡视检查内容"。可选"监测项目"列用于精确匹配阈值配置。
3. **指标口径**：累计量/本次变化量/变化速率**原样引用填报值，不重新推算**；脚本只做表内一致性校核（表 E：高程差×1000 vs 变化量(mm)；表 C/D：本次测值−上次测值 vs 本次变化），不一致标待复核、不改数。
4. **表尾文字**：原表已载的工况描述/简要分析原样带出，标注"原表已载内容，供审核参考"，不视为系统结论；表 G 的巡视检查结果并入巡视记录。
5. **局限**：单期断面数据无时间序列，粗差识别、速率复算不适用；阈值单位须与附录表列单位一致（表 E 变化量栏为 mm）。
6. **解析依赖**：openpyxl（`pip install openpyxl`）。

## 汇总表（render_summary.py 输出）的格式修改声明

汇总表 xlsx 以附录 A~G 表式为基准，经确认的格式修改仅三处，并在"汇总"页说明中列明：

1. 各表主表增加"预警等级"列（红/橙/黄以底色区分）；
2. 表 B 增加"点号"列（原表式点号在表头，逐深度分行后需逐行对应）；
3. 超限与待复核信息除写入"备注"列外，在"汇总"页集中列示。

保留附录表式的表头区、表尾"工况描述""简要分析及判断性结论"、"工程负责人/监测单位"与页码，另加"编制/审核/签发"留空待签栏。
