# 日报修订的实际变化

下表摘要来自两版真实模型正文；具体原文见两版正文结构.json和新版Excel“修订前后对照”。

| 复核关注点 | 修订前 | 修订后 |
|---|---|---|
| 统计口径 | 说明正常、预警、未知的条目数量 | 进一步明确“条目数量不是测点数量”，整体预警不表示每条观测都超限 |
| 地表沉降SIM10-T1-P2 | 主要给出累计26mm及利用率1.3 | 明确累计已触发测试控制要求，而变化速率约3.432mm/d未触发，避免概括成累计与速率都超限 |
| 平台测点SIM10-T1-P5 | 未单独解释零变化平台 | 补充累计22mm、本次变化0mm，说明零变化不代表累计风险解除 |
| 净空收敛SIM10-T4-P6 | 一般性建议结合曲线和现场资料复核 | 针对该点建议核对原始观测、测线方向及工况，不推断支护失稳、不声称已复测或处置 |
| 日报附表口径 | 泛述四类测项汇总 | 明确“本表为日报当日全部观测明细”，不套用周期代表值口径 |
| 追溯与回应 | 无本次工程师退回意见 | 总评加3条测项意见全部逐项回应，增加原意见及正文前后对照表 |

这些修改没有改变任何原始观测、风险等级或项目控制值。报告仍是供工程师复核的草稿。
