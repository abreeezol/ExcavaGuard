## 数据结构和场景

- 时间：2026-11-11 00:00至2026-11-17 23:50，上海时区，每10分钟一次，无缺测。
- 地表沉降、建筑沉降、拱顶沉降、净空收敛各一个数据sheet，另有说明sheet。
- 每类6个测点，共24个通道；每通道1008条，每个数据sheet6048条，合计24192条。
- 每类P1平稳、P2累计渐超、P3短时速率超限后恢复、P4反向变形待核、P5厘米输入的累计超限平台、P6持续速率超限。
- 文件有`data_origin=simulated`，`source_metadata.source_dataset`保存模拟数据集标识。

## 工作台手动测试

1. 按根README启动项目，进入`/workbench`，创建独立测试工程，选择“隧道工程”。
2. 确认工程类别“城市轨道交通”、工法“矿山法／钻爆法”、阶段“施工”、特殊条件“无已确认特殊条件”。按下面表格填写各测项控制要求，来源标明SIMULATED测试方案，输入语义为累计量；参数JSON用于填写工程设置，不是监测表或规范上传文件。
3. 输入方式三选一：上传多sheet工作簿；或分别上传`inputs/separate-files/`的4个XLSX并在同工程一起选中；或上传等价长表CSV。**三种方式不能同时选入同一次运行，以免重复观测。**无需手工拆sheet、合表或修改原始数值。
4. 检查解析结果。多sheet文件应识别4张数据表、24192条；四文件方式应每份6048条、合计24192条。
5. 日报选择2026-11-17，应交付3456条当日观测，保留此前历史计算当日首条速率。周报选择2026-11-11至17，完整区间24192条，24个通道代表观测及完整周期明细。
6. 默认AI模式需要配置LLM与本地隧道规范索引；模板模式不调用LLM，但同样需要规范索引完成全目录核查。只做确定性计算时可取消“生成并审计报告”。
7. 打开报告“规范检索覆盖”工作表，核对16本规范均有核查记录；本工程5本有效且适用规范取得候选，其余逐项说明范围或效力限制。不要求把不适用规范强行当依据。
8. 如需验证工程师反馈，审查通过后选择“退回修改”，写总评或逐项意见，点击“载入输入并按退回意见重编”后运行。新版查看“工程师意见回应”和“修订前后对照”，数值、风险和原稿不应被文字意见改写。

### 仅供测试的控制要求

| 测项 | 累计控制值（mm） | 速率控制值（mm/d） | 输入语义 |
|---|---:|---:|---|
| 地表沉降 | 20 | 4 | 累计沉降，向下为正 |
| 建筑沉降 | 15 | 3 | 累计沉降，向下为正 |
| 拱顶沉降 | 25 | 5 | 累计沉降，向下为正 |
| 净空收敛 | 12 | 2.4 | 累计位移，向内为正 |

P5虽然以cm输入，控制值仍按界面mm/mm/d填写，程序负责量纲换算。控制值均为模拟方案，不能直接用于真实工程。

## 自动核对与复现

在仓库根目录使用Linux/WSL Node和项目Python虚拟环境。首先安装根README中的依赖；默认测试不应读取真实账号，下面命令使用隔离测试配置。

```bash
source .venv/bin/activate
python tools/test/check_tunnel_test_data.py
npm run test:tunnel-data
```

`check_tunnel_test_data.py`核对所有输入SHA256、24通道、1008时刻、10分钟间隔、多sheet/四文件/CSV等价和模拟标记，不调用模型或规范服务。

`test:tunnel-data`执行实际上传及分析API、七天日报、模板周报、全规范核查和异常拦截。报告测试要求本地隧道索引已按[根README](../../README.md#隧道知识库部署)准备；克隆代码不会自动提供`engineering-adapters/tunnel-monitoring/knowledge/knowledge.sqlite3`索引。索引缺失必须先构建，不能把失败当成已验收。

需要显式调用真实模型时，先在本地`.env.local`配置`LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`并准备规范索引，再运行：

```bash
npm run test:tunnel-ai
npm run test:tunnel-feedback
```

第一条测试真实模型日报和周报，第二条执行模拟工程师退回、关联重编、双层审查和三件套下载。它们会调用配置的模型服务。测试使用临时工程，运行结果分别保存在`var/acceptance/tunnel-7day-10min/`和`var/acceptance/tunnel-engineer-feedback/`，不提交私有状态或逐条大体积转储。

重新生成全部输入（会重写本目录`inputs/`中的模拟文件及SHA清单）：

```bash
python tools/test/generate_tunnel_10min.py
```
