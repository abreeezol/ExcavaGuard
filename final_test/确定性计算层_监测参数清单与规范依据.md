## 二、核心计算公式

### 2.1 累计变化量（Cumulative Change）

$\Delta_{cum} = V_{current} - V_{baseline}$

| 字段             | 说明          |
| -------------- | ----------- |
| $\Delta_{cum}$ | 累计变化量（mm）   |
| $V_{current}$  | 本次观测值（mm）   |
| $V_{baseline}$ | 初始值/基准值（mm） |

**规范依据**：GB50497-2019 第9.0.7条："仪器监测项目各监测点的本次测试值、单次变化值、变化速率以及累计值"

**数据质量规则**：

- 初始值应在测点安装稳定后测定，次数不应少于2次（JGJ120-2012 8.2.18）
- 若初始值缺失，标记为 `MISSING_BASELINE`，暂停累计值计算

---

### 2.2 本次变化量（Single Change）

$\Delta_{single} = V_{current} - V_{previous}$

| 字段                | 说明        |
| ----------------- | --------- |
| $\Delta_{single}$ | 本次变化量（mm） |
| $V_{current}$     | 本次观测值（mm） |
| $V_{previous}$    | 上次观测值（mm） |

**规范依据**：GB50497-2019 第9.0.7条："单次变化值"

**数据质量规则**：

- 若上次观测值缺失，标记为 `MISSING_PREVIOUS`，本次变化量标记为待复核
- 若两次观测间隔超过正常监测频率的2倍，标记为 `IRREGULAR_INTERVAL`

---

### 2.3 变化速率（Rate of Change）

$v = \frac{|\Delta_{single}|}{\Delta t}$

| 字段                | 说明         |
| ----------------- | ---------- |
| $v$               | 变化速率（mm/d） |
| $\Delta_{single}$ | 本次变化量（mm）  |
| $\Delta t$        | 两次观测间隔（天）  |

**规范依据**：GB50497-2019 第8.0.3条："变形监测预警值应包括监测项目的累计变化预警值和变化速率预警值"

**数据质量规则**：

- 若 $\Delta t \leq 0$，标记为 `INVALID_INTERVAL`，速率计算弃权
- 若 $\Delta t > $ 正常监测周期的3倍，速率标记为 `SUSPECT_RATE`，建议复核

---

### 2.4 多日平均变化速率（Multi-day Average Rate）

$\bar{v}_n = \frac{|V_{current} - V_{n\_days\_ago}|}{n}$

| 字段                 | 说明             |
| ------------------ | -------------- |
| $\bar{v}_n$        | n日平均变化速率（mm/d） |
| $n$                | 天数（建议3日、7日）    |
| $V_{n\_days\_ago}$ | n天前的观测值        |

**应用场景**：平滑单日波动，识别持续加速趋势

---

### 2.5 趋势斜率（Trend Slope）

采用最小二乘法对最近 $n$ 个观测点拟合线性趋势：

$y = kx + b$

| 字段  | 说明          |
| --- | ----------- |
| $k$ | 趋势斜率（mm/d）  |
| $x$ | 时间序列（天）     |
| $y$ | 累计变化量序列（mm） |

**应用场景**：判断变形是否处于加速、匀速或减速阶段

---

### 2.6 支撑轴力/锚杆轴力校核

$\eta = \frac{F_{current}}{F_{design}} \times 100\%$

| 字段            | 说明                |
| ------------- | ----------------- |
| $\eta$        | 轴力比值（%）           |
| $F_{current}$ | 当前轴力实测值（kN）       |
| $F_{design}$  | 设计允许值/承载能力设计值（kN） |

**规范依据**：

- GB50497-2019 表8.0.4：支撑轴力最大值（60%~80%）$f_2$（$f_2$为构件承载能力设计值）
- JGJ120-2012 8.2.23：支护结构构件内力超过其设计值时应立即报警

---

### 2.7 地下水位变化量

$\Delta h = h_{current} - h_{baseline}$

| 字段             | 说明         |
| -------------- | ---------- |
| $\Delta h$     | 水位变化量（mm）  |
| $h_{current}$  | 当前水位高程（mm） |
| $h_{baseline}$ | 初始水位高程（mm） |

**规范依据**：GB50497-2019 表8.0.5：地下水位变化速率500mm/d，累计值1000~2000mm（常年变幅以外）

---

### 2.8 建筑倾斜度

$i = \frac{\Delta_{max} - \Delta_{min}}{L}$

| 字段             | 说明            |
| -------------- | ------------- |
| $i$            | 倾斜度           |
| $\Delta_{max}$ | 最大沉降值（mm）     |
| $\Delta_{min}$ | 最小沉降值（mm）     |
| $L$            | 建筑基础两点间距离（mm） |

**规范依据**：GB50497-2019 表8.0.5注：建筑整体倾斜度累计值达到2/1000或倾斜速度连续3d大于0.0001H/d（H为建筑承重结构高度）时应预警

---

### 2.9 裂缝宽度变化量

$\Delta w = w_{current} - w_{previous}$

| 字段             | 说明          |
| -------------- | ----------- |
| $\Delta w$     | 裂缝宽度变化量（mm） |
| $w_{current}$  | 本次裂缝宽度（mm）  |
| $w_{previous}$ | 上次裂缝宽度（mm）  |

**规范依据**：GB50497-2019 表8.0.5：建筑结构性裂缝（既有裂缝）持续发展且累计值1.5~~3mm时应预警；新增裂缝宽度0.2~~0.25mm时应预警

---

### 2.10 稳定性安全系数（预留接口）

#### 2.10.1 整体滑动稳定安全系数

$K_s = \frac{\sum (c_i l_i + W_i \cos\theta_i \tan\varphi_i)}{\sum W_i \sin\theta_i}$

**规范依据**：JGJ120-2012 4.2.3：一级≥1.35，二级≥1.3，三级≥1.25

#### 2.10.2 坑底隆起稳定（预留）

**规范依据**：JGJ120-2012 4.2.4

#### 2.10.3 渗透稳定（预留）

**规范依据**：JGJ120-2012 附录C：坑底突涌稳定Kh≥1.1；流土稳定一级Kf≥1.6，二级≥1.5，三级≥1.4

> **说明**：稳定性计算需要地质参数（土体重度、内摩擦角、粘聚力等），当前数据中缺少这些参数，标记为"待补充"。后续可通过项目专项方案或勘察报告补充。

### 3.13 危险报警条件（强制性条文）

**规范依据**：GB50497-2019 第8.0.9条（强制性条文）

当出现下列情况之一时，**必须立即进行危险报警**：

1. 基坑支护结构的位移值突然明显增大或基坑出现**流砂、管涌、隆起、陷落**等
2. 基坑支护结构的支撑或锚杆体系出现**过大变形、压屈、断裂、松弛或拔出**的迹象
3. 基坑周边建筑的结构部分出现**危害结构的变形裂缝**
4. 基坑周边地面出现**较严重的突发裂缝或地下空洞、地面下陷**
5. 基坑周边管线变形突然明显增长或出现**裂缝、泄漏**等
6. 冻土基坑经受冻融循环时，基坑周边土体温度显著上升，发生明显的**冻融变形**
7. 出现基坑工程设计方提出的其他危险报警情况

## 四、问题识别与风险分级

### 4.1 变形过大

**识别条件**（满足任一即触发）：

| 判定项    | 判定标准                                 | 规范依据                      |
| ------ | ------------------------------------ | ------------------------- |
| 累计值超限  | $\|\Delta_{cum}\| \geq$ 对应安全等级累计值预警值 | GB50497-2019 表8.0.4/8.0.5 |
| 变化速率超限 | $v \geq$ 对应安全等级速率预警值                 | GB50497-2019 表8.0.4/8.0.5 |
| 连续接近预警 | 连续3次 $v \geq$ 70%速率预警值               | GB50497-2019 第8.0.3条      |
| 趋势加速   | 趋势斜率 $k > 0$ 且呈增大趋势                  | 项目内部规则                    |
| 多点联动   | 同一区域多个测点同时超限或接近超限                    | GB50497-2019 第8.0.9条      |


**风险等级**：

| 等级   | 判定条件                         |
| ---- | ---------------------------- |
| 正常   | 所有指标均在预警值50%以下               |
| 关注   | 任一指标达到预警值50%~70%             |
| 预警   | 任一指标达到预警值70%~100%，或连续3次超过70% |
| 报警   | 任一指标达到或超过预警值                 |
| 危险报警 | 符合GB50497-2019第8.0.9条强制性条文条件 |

---

### 4.2 渗漏水/地下水异常

**识别条件**（满足任一即触发）：

| 判定项     | 判定标准                           | 规范依据                |
| ------- | ------------------------------ | ------------------- |
| 地下水位突变  | 日变化量≥500mm/d，或累计变化≥1000~2000mm | GB50497-2019 表8.0.5 |
| 渗漏水记录   | 现场备注出现渗水、漏水、涌水、流砂、管涌等关键词       | JGJ120-2012 8.2.22  |
| 水位与变形同步 | 地下水位异常变化与周边沉降或坑内变形同步增大         | 项目内部规则              |
| 渗透破坏征兆  | 出现流土、管涌现象                      | JGJ120-2012 附录C     |

**风险等级**：

| 等级   | 判定条件                       |
| ---- | -------------------------- |
| 正常   | 水位变化平稳，无渗漏水记录              |
| 关注   | 水位变化速率接近预警值50%，或出现轻微渗水记录   |
| 预警   | 水位变化速率接近预警值70%，或出现明显渗漏记录   |
| 报警   | 水位变化达到预警值，或出现涌水、流砂记录       |
| 危险报警 | 出现流土、管涌现象（JGJ120-2012 附录C） |

---

### 4.3 支护受力异常

**识别条件**（满足任一即触发）：

| 判定项     | 判定标准                       | 规范依据                |
| ------- | -------------------------- | ------------------- |
| 支撑轴力超限  | 轴力比值 $\eta \geq$ (60%~80%) | GB50497-2019 表8.0.4 |
| 锚杆轴力异常  | 轴力低于预应力设计值的80%（松弛）或超过设计值   | GB50497-2019 表8.0.4 |
| 围护墙内力超限 | 内力达到承载能力设计值的(60%~80%)      | GB50497-2019 表8.0.4 |
| 轴力突降    | 单次变化量超过历史平均变化量的3倍          | 项目内部规则              |
| 与工况不匹配  | 轴力变化与开挖、拆撑、降水工况不匹配         | 项目内部规则              |

**风险等级**：

| 等级   | 判定条件                                  |
| ---- | ------------------------------------- |
| 正常   | 轴力在设计值的50%以下                          |
| 关注   | 轴力达到设计值的50%~60%                       |
| 预警   | 轴力达到设计值的60%~80%                       |
| 报警   | 轴力达到或超过设计值的80%                        |
| 危险报警 | 支撑出现压屈、断裂、松弛或拔出迹象（JGJ120-2012 8.2.23） |

---

### 4.4 支护失稳风险

**识别条件**（满足任一即触发）：

| 判定项      | 判定标准                | 规范依据                |
| -------- | ------------------- | ------------------- |
| 变形持续加速   | 趋势斜率 $k > 0$ 且连续增大  | JGJ120-2012 8.2.23  |
| 位移速率不收敛  | 位移速率增长且不收敛          | JGJ120-2012 8.2.23  |
| 多点同步异常   | 多个临近测点变形同步异常        | GB50497-2019 8.0.9  |
| 支撑受力异常   | 支撑轴力异常增大或突降         | JGJ120-2012 8.2.23  |
| 深层位移曲线异常 | 深层水平位移曲线出现明显拐点      | 项目内部规则              |
| 坑底隆起     | 坑底隆起累计值≥30~60mm     | GB50497-2019 表8.0.4 |
| 整体滑动     | 安全系数 $K_s <$ 对应等级要求 | JGJ120-2012 4.2.3   |

**风险等级**：

| 等级   | 判定条件                                        |
| ---- | ------------------------------------------- |
| 正常   | 变形稳定，速率收敛                                   |
| 关注   | 变形速率略有增大，但未加速                               |
| 预警   | 变形持续加速，或出现多点联动                              |
| 报警   | 出现失稳征兆（位移不收敛、支撑异常等）                         |
| 危险报警 | 符合GB50497-2019第8.0.9条或JGJ120-2012第8.2.23条条件 |

### 4.5 数据质量异常

**识别条件**（满足任一即触发）：

| 判定项   | 判定标准                  | 处理规则                            |
| ----- | --------------------- | ------------------------------- |
| 缺测    | 监测周期内无数据记录            | 标记`MISSING_DATA`，暂停受影响指标判定      |
| 粗差    | 单次变化量超过历史平均的5倍或物理上不可能 | 标记`OUTLIER`，保留原始值，提示复核          |
| 单位错误  | 单位不在支持列表（mm、cm、m）     | 标记`UNSUPPORTED_UNIT`，整批弃权       |
| 测点错配  | 测点编号与项目配置不匹配          | 标记`POINT_MISMATCH`，提示核对         |
| 重复记录  | 同一测点同一时间存在多条记录        | 标记`DUPLICATE_RECORD`，提示核对       |
| 传感器漂移 | 连续多次观测值相同（flatline）   | 标记`SENSOR_DRIFT`，提示检查           |
| 时间异常  | 时间戳格式错误或时间倒流          | 标记`INVALID_TIMESTAMP`，整批弃权      |
| 间隔异常  | 两次观测间隔超过正常频率的3倍       | 标记`IRREGULAR_INTERVAL`，速率标记为待复核 |

**风险等级**：

| 等级 | 判定条件                       |
| -- | -------------------------- |
| 正常 | 数据完整，无异常标记                 |
| 关注 | 存在轻微异常（如单次间隔略长），但不影响主要指标计算 |
| 预警 | 存在影响部分指标计算的异常（如缺测、粗差）      |
| 报警 | 存在影响整体判定的严重异常（如单位错误、大面积缺测） |

## 十、当前数据资产分析

### 10.1 多传感器隧道监测数据集

- **来源**：Zenodo公开数据集（DOI: 10.5281/zenodo.20768869）
- **传感器类型**：DW（位移）、MG（岩石锚杆应力）、SY（孔隙水压力）
- **数据格式**：CSV，包含observations、daily_aligned、sensor_metadata等
- **适用性**：可作为数据质量检查、阈值计算、趋势分析的测试数据源
- **局限性**：传感器类型与深基坑监测参数不完全对应，需做映射转换

### 10.2 地下室粘土隆起监测数据

- **来源**：伦敦粘土隆起监测案例（1967-1989）
- **数据类型**：隆起监测数据、孔隙水压力、不排水抗剪强度
- **适用性**：可用于坑底隆起、孔隙水压力监测参数的模拟数据生成参考
- **局限性**：数据为历史案例，时间跨度长，需转换为日报格式

### 10.3 黏土基坑开挖案例数据库

- **来源**：EXCAV-CLAY152830数据库
- **数据类型**：基坑开挖案例参数
- **适用性**：可用于案例知识库建设
- **局限性**：当前未解析具体字段内容
