# SIMULATED 项目规则变更演示数据

全部为人工构造测试资料，不是真实规范、设计要求或实测数据。3天、2测点，每3小时一次，共48条。

1. 在测试项目选择隧道工程：城市轨道交通、矿山法、施工阶段、无特殊条件。
2. 监测参数选择拱顶沉降，语义为累计沉降（向下为正）；原项目累计控制值12 mm，来源填写“SIMULATED原项目测试要求”，确认。无需输入速率控制值。
3. 上传三份按日期命名的CSV，生成2026-11-02日报作为基线；按原12 mm要求均未触发累计阈值。
4. 在项目补充规范上传本目录Markdown，名称和版本自行明确标注SIMULATED，地区填“模拟测试”，适用范围填本测试项目矿山法施工阶段拱顶累计沉降。
5. 点击“分析规则变更”，核对原文、6 mm、>=、预警、工法/阶段；可以先选择基线记录试算。生成模型可能保留待核项，应按实际提案核验，不假定每次输出相同。
6. 管理员/复核工程师逐条接受，说明“仅用于本测试项目，6 mm补充提醒与12 mm并行，不替代正式控制要求”，再发布。重新生成2026-11-02日报，应出现达到6 mm的项目补充提醒；依据应显示测试要求名称和条款。
7. 测试意见退回：“仅适用于SIM-CROWN-01”，重新分析后核对测点范围；也可直接编辑候选测点并填写理由，再确认发布。
8. 停用补充规则后重新生成日报，应恢复仅按原12 mm要求核查；历史已生成日报保持原版本。项目配置修改后原补充规则要求重审。

注意：第一天两测点均未到6 mm；第二天SIM-CROWN-01全日达到6 mm，SIM-CROWN-02在06:00开始达到6 mm；第三天两测点均达到6 mm，三天所有观测均小于12 mm。其他质量或适用性问题仍应独立披露，不能把“累计阈值未触发”概括为工程安全。
